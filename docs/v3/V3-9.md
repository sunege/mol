**依存: 全部**

**目的**: Claude の作業ブラウザでは確かめられないところを、ユーザーに見てもらう。

## 前提

- **Claude の作業ブラウザは WebGL が使えない**（GPU 無効の Chromium）。3D の見た目と
  クリック操作はユーザーに Firefox で確認してもらう。パネル・Worker・IndexedDB は
  Browser ツールで検証済みのはず。
- 講義で使う PC: **Windows 11 / i5-1235U（P 2 + E 8、12 スレッド、15 W）/ Chrome**。
  `poolSize` は 3 になる。**その PC での実測はまだ無い。**

### V3-5 で入ったもの（2026-09-22）

- **ファイルの `version` は 1 のまま**（記録の形を変えず、段は `model` から引く）。v2 までに

### V3-6 で入ったもの（2026-09-22）

### V3-7 で入ったもの（2026-09-22）

- **4 の数値まで残るのは、ページが cross-origin isolated のときだけ**（`vercel.json` の
  COOP/COEP。デプロイした後に、開発者ツールのコンソールで `crossOriginIsolated` が `true` か
  を見る）。`true` なら「中止」→ カード「止めています · いまの一歩が終わるまで」、ボタンが
  「すぐ止める」→ 一歩の後に止まり、形・数値・状態「途中で止めました（段）」・記録「途中」・
  電子の雲が出る。「すぐ止める」を押すと形だけ残り、数値は `—`。`false`（header が無い、他サイトに
  埋め込まれている）なら形だけ残る。
- **dev サーバ（5173）は再起動しないと header が付かない。**
- **押し直すと平らな分子は揺らされる**（当時の挙動）: 止めたベンゼンを続けると 3 歩で済まず、
  Claude のブラウザでは 17 歩・約 90 秒かかった。**V3-8 で変えた**（下の節）ので、今は続きから
  数歩で終わるはず。4 でそこを見てもらう。
- 止めた記録を開いたときの形の調整は「途中で止まりました · N 回動いたところまで」（時間切れと
  区別しない）。

### V3-8 で入ったもの（2026-09-23）

- **実測の値（Node、この開発機。3 回の最小値）**。講義 PC の数字はこれと比べる。詳しい表は
  dev-notes「v3 の実測」。

  | | 形を探す | 形を測る |
  | --- | --- | --- |
  | 水（プリセット） | 0.8 秒 | 1.9 秒 |
  | C₃H₆（手で作った形から） | 31〜80 秒 | 125〜271 秒 |
  | C₃H₆（「形を探す」で見つけた形から） | — | 42〜55 秒 |
  | ベンゼン（プリセット） | 13.5 秒 | **176 秒** |
  | ベンゼンの一点計算 | 3.3 秒 | 71 秒 |

  **1 歩（＝「中止」を押してから止まるまでの待ち）はベンゼンを測ると最長 19 秒**、C₃H₆ で 5 秒。
  **Worker の線形メモリはベンゼンを測ると 420〜625 MiB**（探すと 105 MiB）。前面 ＋ プール 3 本で
  最悪 1.1 GiB になるので、**3 で Chrome のタスク マネージャも見てもらう**。
- **時間の目安の文言を実測に直した**: 「形を探す」＝ `数秒〜数十秒`（前は `数秒`）、
  「形を測る」＝ `数十秒〜数分`（そのまま）。1 で実感と合うかを見てもらう。
- **予算は変えていない**（`OPTIMIZE_BUDGET_SECONDS` 1800 秒、候補 10 分）。正常な計算で最長
  6.7 分だったため。Rust と `web/src/wasm/` は触っていない。
- **揺らすのは手で作った・編集した形だけになった**（`needsNudge` / App の `handBuilt`）。
  プリセット・記録から開いた形・**緩和から出てきた形**は揺らさない。**Claude のブラウザでは
  原子を置けないので、1・4 と一緒に見てもらいたいのはここ**:
  - 手で作った平らな形（平面のメタンなど）を「安定な形にする」と、ちゃんと立体になること
    （揺らしは今までどおり効いている）。
  - ベンゼンを「安定な形にする」→ もう一度押すと「すでに安定な形でした」で終わること
    （Claude のブラウザでは 3 歩 17.09 秒 → 5.63 秒）。「形を探す」→「形を測る」も同じ道で、
    これが無いとベンゼンを測るのに 372 秒かかっていた。
- **「形を測る」を選んでいて、画面の形が手で作ったもののときだけ**、段の説明の下に
  「手で作った形は、先に「形を探す」で落ち着かせてから測ると早く終わります。」の一行が出る
  （止めも妨げもしない助言）。プリセット・記録・緩和の結果では出ない（Claude のブラウザで確認済み）。
  **手で作った形で出ることの確認は 1 でお願いしたい。**

## 見てもらうこと

1. **段の選択**: 「形を探す」と「形を測る」が計算ごとに選べ、計算中は固まること。
   説明の一行が読めるか、時間の目安が実感と合うか。
2. **水とメタンで角度が教科書に近づくこと**（水 96.7° → 103.7° 付近）。
   ここが v3 の目的そのもの。
3. **ベンゼンを「形を測る」で回す**: 何分かかるか、前面が固まらないか、
   ファンと本体の熱（講義 PC）。
4. **中断**: 途中で「中止」を押すと**形が残り**、数値と理由が出ること。
   押し直して続けられること。
5. **記録**: 段の違う記録が別の群に並び、見出しでどちらの段か読めること。
   段をまたいで順位がつかないこと。
6. **探索（「いろいろな形を試す」）が今までどおり速いこと**（形の段に固定されている）。
   前面で「形を測る」を選んでいても速いこと。
7. 3D の見た目・測定ラベル・進捗カードの重なりが v2 から壊れていないこと。
