# V3-4 計算ごとに段を選ぶ UI

**依存: V3-3**

**目的**: 「形を探す」と「形を測る」を、計算のたびに選べるようにする。

## 前提

- **段は計算ごとに選ぶ**（全体の設定にしない。2026-09-21 ユーザー決定）。既定は「形を探す」。
- **名前はこの 2 つで確定**。「正しく測る」「精度 高」などにしない
  （誤差は許容する前提だから／実測では上の段が常に良いわけではないから）。
- **F4: 画面に基底・汎関数・電荷・多重度を出さない。** 段の説明も目的と時間の言葉だけ。
- 文言と数値は `web/src/components/` のテスト付きモジュールに分ける慣習
  （`components/search.ts` と `components/records.ts` がその形）。
- ボタンは `App.tsx` の「安定な形にする」／計算中は「中止」（`computing ? cancelCalculation : relax`）。

### V3-3 で入ったもの（2026-09-21）

- **型は `web/src/worker/protocol.ts` の `ModelLevel`**。クライアントは
  `client.scf(z, xyz, onProgress?, level?)` と
  `client.optimize(z, xyz, onStep, onProgress?, budgetMs?, level?)`（段は**末尾**）。
  App で渡す先は 3 か所: `calculate()`（「この形のまま計算」）・`relax()`・`solveForSurface()`
  （記録を開いたときの等値面）。**省略すると `'shape'`**（既定は Rust の `basis_for` の 1 か所
  だけ）だが、App は**いつも明示して渡す**。知らない名前は `error` の応答になる。
- 段がエンジンまで届くことと、`'shape'`／省略が以前とビット単位で同じことは V3-3 で確かめ済み。
  パネルで確かめるときの目安: 水の一点計算は **`shape` −74.732 Ha、`measure` −75.844 Ha**
  （Node で 0.2 秒と 0.4 秒。水の緩和は 0.7 秒と 1.7 秒）。
- **V3-5 が入るまでの記録の扱い（ここで塞ぐ）**: `createRecord()` は段に関係なく
  `model: ENGINE_MODEL`（STO-3G の文字列）を書く。このチケットだけで `'measure'` の緩和を記録
  すると「形を探す」の群に混ざって**順位と谷を壊し、IndexedDB に残り続ける**。そこで
  **`'measure'` の緩和は記録しない**（`relax()` の `createRecord` → `keepRecord` →
  `setOpenRecordId` を `'shape'` のときだけにし、「V3-5 で外す」とコメント）。V3-5 が外す。
  **`'measure'` のときは代わりに `setOpenRecordId(null)`**: `relax()` は開始時に開いている記録を
  閉じない（閉じるのは編集の `invalidateResult()`）ので、飛ばすだけだと、記録を開いて
  そのまま緩和したときに前の記録が開いたまま `measure` の結果の横に残る。
- **等値面のための一点計算は、選択中の段ではなく画面の結果の段で解く**: 選択は計算中以外は
  変えられるので、選択の値を使うと食い違う。`solveForSurface()` が呼ばれるのは記録を開いたとき
  だけなので、V3-5 までは記録の段＝いつも `'shape'`。
- **F4 の禁止語**: `records.test.ts` のリストは `'基底', 'STO-3G', '汎関数', 'LDA', '電荷',
  '多重度', 'DFT'` で、**`6-31G` が無い**。`level.test.ts` では足す。

## やること

1. `web/src/components/level.ts`（新規）: 段の並び、ラベル、添える一行、時間の目安。
   テストは `level.test.ts` で、**基底・汎関数・電荷・多重度の語が出てこないこと**を
   `records.test.ts` と同じやり方で固定する。
   - 「形を探す」… 数秒。どんな形に落ち着くかを見る
   - 「形を測る」… 数十秒〜数分。結合の角度を数値として読む
   （**ベンゼンで 2 分前後**。実測は V3-8 で確定させ、そこで文言を直す。）
2. パネルに選択を足す（`App.tsx` に `const [level, setLevel] = useState<ModelLevel>('shape')`）。
   **計算中は変えられない**（進行中の結果と食い違うため）。
3. `relax()` と単発の SCF（等値面のための一点計算を含む）に `level` を渡す。
   **等値面のための一点計算は、その結果を出した段と同じ段で解く**
   （違う段で解くと数値が食い違う）。
4. 記録から開いたときは、**その記録の段を選び直す**（V3-5 と合わせる）。
