# V3-1 エンジンが基底を選べるようにする（Rust）

**目的**: `dft-core` が STO-3G と 6-31G\* のどちらでも解けるようにする。UI も wasm もまだ触らない。

## 前提（これだけ知っていれば着手できる）

- 今は `BasisSet::sto3g(&molecule)` が唯一の入口で、`scf/mod.rs` の `System::build` /
  `build_with_grid` がそれを決め打ちで呼んでいる。
- `basis/mod.rs` は**一般の l の Cartesian ガウス**に対応済み（`cartesian_powers` は libcint と
  同じ並び、d の成分ごとの規格化も入っている）。`integrals` の McMurchie-Davidson も l に
  依存しない。**d 関数のために新しい積分コードは要らない**（検証済み: 水とベンゼンを
  6-31G\* で解くと PySCF と 1e-6 Ha で一致する）。
- 6-31G\* は **H–Ar のすべてにあり、最大 l = 2**。スコープ（H–Ar）は変わらない。
- **規約: 表を記憶から書かない。** 基底表は `scripts/gen_reference.py` が作る生成物で、
  手編集しない。6-31G\* は一般縮約ではないので、`write_sto3g()` のループがそのまま使える
  （各行が `[指数, 係数]` の 2 要素）。

## やること

1. **`scripts/gen_reference.py`**: `write_631gs()` を足す。`write_sto3g()` のコピーで、
   `gto.basis.load("6-31g*", symbol)` にするだけ。出力は
   `crates/dft-core/src/basis/b631gs_data.rs`（`pub static B631GS: [&[ShellDef]; 18]`）。
   ヘッダの「GENERATED by ... Do not edit by hand.」も同じ形で。`main()` に足す。
2. **`basis/mod.rs`**: `pub enum BasisKind { Sto3g, B631Gs }`（`Copy`）と
   `BasisSet::build(kind, &molecule)`。`sto3g()` は `build(Sto3g, ..)` を呼ぶ薄い包みとして残す
   （既存のテストがそのまま通る）。
3. **`scf/mod.rs`**: `System` に `pub kind: BasisKind` を持たせ、`System::build` /
   `build_with_grid` が `kind` を受け取る。**`System` が自分の基底を覚えていれば、下の 2 つは
   引数を増やさずに済む。**
4. **`scf/guess.rs`**: `atomic_density(z)` が内部で `System::build` を呼んでいる。
   **ここを直さないと 6-31G\* で壊れる**（原子ブロックの大きさが合わず、release では添字外に
   なる）。`atomic_density(z, kind)` にして、キャッシュの鍵も `(z, kind)` にする。
5. **`opt/mod.rs`**: 306 行あたりで毎歩 `System::build` を呼んでいる。`system.kind` を渡す。
6. 呼び出し側の更新: `crates/dft-wasm/src/lib.rs`（当面 `BasisKind::Sto3g` を固定で渡す。
   段を通すのは V3-3）、`examples/profile.rs`、`examples/basis_cost.rs`。

## 完了条件

- `cargo test --workspace` が通る（既存のテストは STO-3G のままで、値が 1 つも動かないこと）。
- 新しいテストを `tests/reference_integrals.rs` に 1 本:
  **`b631gs_table_matches_reference()`** — 既存の `sto3g_table_matches_reference()` と同じ形で、
  `tests/data/integrals_h2o_631gs.json` の `shells`（PySCF が使った 6-31G\* のシェル）と
  `BasisSet::build(B631Gs, ..)` の並び・l・指数・係数が一致することを見る。
  **この JSON は既にあり、d シェルを含む。**
- `cargo run --release --example basis_cost -- <入力>` が 6-31G\* で回ること
  （この例は `System` を自分で組み立てているので、V3-1 の後は `System::build` を使う形に
  書き直してよい）。
