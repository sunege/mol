# V3-2 6-31G\* の参照値とテスト

**依存: V3-1（`BasisSet::build` と `System` の `kind` がある前提）**

**目的**: 6-31G\* の経路を、STO-3G と同じ厳しさで参照値に固定する。

## 前提

- **規約: 参照値を記憶から書かない。** すべて `scripts/gen_reference.py`（PySCF）の生成物か、
  テストの中で独立な経路から導く。
- `gen_reference.py` には既に **`integral_reference(key, name, basis, cart, full_eri)`** があり
  （`integrals_h2o_631gs.json` はこれで作られている）、**`scf_reference(key, name, with_density)`**
  と **`relaxed_geometry(name, multiplicity)`** は STO-3G 決め打ち。
- **Cartesian d を使う**（`cart=True`）。エンジンは Cartesian で、6D と 5D では関数の数が違う
  （ベンゼンで 102 対 96）。
- 6-31G\* で PySCF と一致することは v3-0 で確認済み: 水 −75.844389 対 −75.844388、
  ベンゼン −230.090762 対 −230.090758（どちらもプリセット構造、`lda,vwn5`）。

## やること

1. `scf_reference()` に基底の引数を足し、**水・メタン・アンモニア**の 6-31G\* 版を出す
   （`scf_h2o_631gs.json` など。名前は既存の付け方に合わせる）。ベンゼンは重いので入れない。
2. `relaxed_geometry()` にも基底の引数を足し、**水の 6-31G\* の緩和構造**を 1 つ出す。
   v3-0 の値は r(OH) = 0.9762 Å / ∠HOH = 103.65°（参考。**テストに書き写さず生成物にする**）。
3. `tests/reference_scf.rs` と `tests/optimize.rs` が両方の基底で回るようにする。
4. 勾配: `integrals/deriv.rs` には既に **d シェルの項ごとの有限差分テスト**（`with_d_functions`）
   がある。6-31G\* の実基底で 1 本足せるなら足す（`tests/gradients.rs`）。
5. `npm run build:wasm` はこのチケットでは不要（Rust の公開 API が変わっていなければ）。

## 完了条件

- `cargo test --workspace` が通り、**6-31G\* の SCF・緩和・勾配が参照値に固定されている**。
- `scripts/gen_reference.py` を回し直すと、生成物が差分なしで再現する。

## 迷ったら

- 生成物の作法とグリッドの決め方: `scripts/gen_reference.py` の冒頭と `REFERENCE_GRID_LEVEL`。
