# V3-5 記録が段を持つ

**依存: V3-3**

**目的**: 段が違う記録を混ぜて順位づけしないようにし、一覧でそれが読めるようにする。

## 前提

- `web/src/records/record.ts` に **`ENGINE_MODEL = 'sto-3g/lda-vwn5/fine'`** があり、
  記録は保存時のその文字列を `model` に持つ。
- **`comparisonKey(record) = `model|charge|formula`` なので、`ENGINE_MODEL` を段ごとに分ければ
  段の違う記録は自動的に別の群になる**（古い記録も読めたまま別群に落ちる）。設計済み。
- 規約: **比べてよい組は Hill 式 + 電荷 + `ENGINE_MODEL`**。電荷は内部の比較キーで、
  **画面には出さない**。**同じ谷は 1 kJ/mol 以内**。**時間切れ・回数上限は「途中」で、
  順位にも谷にも入れない。**開いたら数値は記録のもの**（等値面のための一点計算で上書きしない）。
- ファイルは形を変えたら `version` を上げ（`web/src/records/file.ts`）、
  **1 件でも駄目なら全部拒否**。
- 保存は `RecordStore` 越しで、**開けないブラウザでは「残りません」と案内して動かす**。

### V3-3 で入ったもの（2026-09-21）

- 段の型は `web/src/worker/protocol.ts` の **`ModelLevel = 'shape' | 'measure'`**。
- **V3-4 が先に入っていれば、`relax()` に「`'measure'` の緩和は記録しない」ガードがある**
  （記録が段を持つまでの間、STO-3G の `model` で書かれて混ざるのを防ぐもの）。**ここで外す。**
- 群の見出しの禁止語には `6-31G` も足す（`records.test.ts` のリストには無い）。

## やること

1. `ENGINE_MODEL` を段ごとの 2 つにする（例: `'sto-3g/lda-vwn5/fine'` と
   `'6-31gs/lda-vwn5/fine'`）。**`ModelLevel` から引く 1 つの関数**にまとめ、
   「基底・汎関数・最適化グリッドを変えたら書き換える」というコメントを引き継ぐ。
2. 記録を書くときに、計算に使った段の文字列を入れる。
3. **一覧の群の見出しに、どの段の群かを目的の言葉で出す**（`components/records.ts` の
   `groupHeading()`。**F4 に触れないよう、基底名は出さない**）。
4. ファイルの `version` を上げ、古い版を**拒否**する（既存の作法どおり。移行はしない）。
5. 記録を開いたら、その段を選び直す（V3-4 と合わせる）。

## 完了条件

- `npm test` が通る。新しいテスト:
  - 段が違う 2 件が**別の群**になること（`comparisonKey`）。
  - 群の見出しに段が読めて、**禁止語が出ないこと**。
  - 古い `version` のファイルが 1 件でも混ざれば**全部拒否**されること。
- Claude のブラウザで、2 つの段で同じ分子を計算 → 記録が 2 群に割れることを確認。
