# V5-8 記録を左の欄へ

**依存: V5-3, V5-7**

**目的**: 記録を右のパネルから出し、画面の左の畳める欄にツリー（V5-7）で描く。
`RecordsPanel.tsx` はこのチケットで消える。

## 前提

- **画面は 3 列**: 左の欄 236px（畳んで 40px）・3D・右のパネル 340px。`.app` の
  `grid-template-columns` を `var(--explorer) 1fr 340px` にし、畳むと `--explorer: 40px`。
  **Viewer は `ResizeObserver` で追うので、3D の側は何もしない。**
  720px 以下の `@media` は V5-10 で直すので、ここでは**左の欄を `display: none`** にするだけ
  （その間、狭い画面では記録が見えない。V5-10 で戻る）。
- **左の欄の中身**（上から）:
  1. 見出しの行: 「記録」・件数のバッジ・畳むボタン（`IconButton`、くの字）。畳むと縦の細い帯に
     バッジと開くボタンだけが残る。
  2. 道具の行: 「書き出す」「読み込む」（`.btn.small`）と「…」（`IconButton`）。「…」の中は
     「全部消す」。**「〇〇 だけ」のボタンはやめる**（出たり消えたりする）。代わりに**分子の
     フォルダの行の「…」から「この分子だけ書き出す」**（`onExport(formula)`）。
  3. `NOT_KEPT_NOTICE`（記録が残らないブラウザのとき）と `recordNotice`（読み込みの結果）。
  4. ツリー（スクロールするのはここだけ）。記録が無ければ `NO_RECORDS`。
  5. 下端に小さく `ISOMER_CAVEAT`（常に出す。v3 の決定で、順位の読み方の注意）。
     `RECORDS_HINT` は見出しの `title` か「…」の中へ。
- **ツリーの行**:
  - 分子・段・谷は開閉できる行（`aria-expanded`、くの字が回る）。字下げは 1 段 14px。
  - 記録の行を押すと `onOpen(record)`（今の `openRecord`）。開いている記録の行を強調し、
    **その行の下にだけ**アイコンの操作を出す: 再生（`canReplay` のときだけ有効）・名前・削除。
    名前の変更は今の `RecordsPanel` のインライン入力をそのまま移す（Enter で確定・Esc で戻す）。
  - 谷の行は代表の記録の行でもある（押すと代表を開く）。くの字だけが開閉。`×5` の印。
  - 深さの棒（`depthBar(entry, spreadOf(group))`）は行の下端に細く。
  - 落ち着かなかった記録は薄い色で「途中」。
  - キーボード: 行は `<button>` で Tab 移動できればよい（`role="tree"` の矢印キー操作までは要らない）。
- **開閉は覚える**: `expanded: Set<string>`（V5-7 の `id`）と畳んだかどうかを `localStorage` の
  `mol.explorer` に。**読み書きは必ず try/catch**（開けないブラウザでも動く。`RecordStore` と
  同じ考え）。覚えたものが無いノードは `defaultExpanded` に従う。**開いた記録が変わったら、
  その祖先だけは開く**（覚えた閉じ方より優先。画面の記録が見えない、を起こさない）。
- App から渡すもの（今の `<RecordsPanel>` の props とほぼ同じ。`grep -n "<RecordsPanel" App.tsx`）:
  `groups`（`recordGroups`）、`openId`、`kept`、`canImport`、`currentFormula`、`onOpen`、
  `onReplay`、`canReplay`、`onRename`、`onDelete`、`onClear`、`onExport(only)`、`onImport`、`notice`。
  **ハンドラは App のものをそのまま使い、App の中身は変えない。**

## V5-7 で入ったもの

- **木は `records/tree.ts` の `buildRecordTree(groups)`**（`buildTree` ではない）。`groups` は
  App の `recordGroups`（画面の分子を先頭に並べ替えたもの）をそのまま渡す。分子の順は「その分子の
  群が最初に出てきた順」。型は `RecordTree = FormulaNode[]`、`FormulaNode`（`formula`・`count`・
  `children: LevelNode[]`）、`LevelNode`（`group: LogGroup`・`children: (ValleyNode | RecordLeaf)[]`）、
  `ValleyNode`（`head: LogEntry`・`rest: LogEntry[]`）、`RecordLeaf`（`entry: LogEntry`）、
  和は `RecordTreeNode`。どれも `kind` で分ける。
- **`id`**: `f:${formula}`・`g:${group.key}`・`r:${record.id}`・谷は `v:${group.key}:${最古の記録の id}`
  （**チケットの `head.record.id` から変えた**。同じ谷を探索がもう一度見つけると半分は代表より
  わずかに深く、代表が入れ替わって開いた谷が閉じるため。最古は記録を足しても動かない）。
  **1 件だけの谷は `RecordLeaf`（`r:`）で、2 件目が来ると `ValleyNode`（`v:`）に変わる**
  ＝ 開閉の鍵はそこで切り替わる（閉じた谷として出る。葉には開閉が無いので失うものは無い）。
- **`defaultExpanded(tree, { currentFormula, openId }): Set<string>`**: 画面の分子とその段を開く。
  `openId`（記録の id。`r:` は付けない）が谷の `rest` にあれば、その谷・段・分子を開く（分子が
  画面のものでなくても）。代表（`head`）や葉なら谷は開かない。覚えた開閉より優先する「開いた記録の
  祖先」は、同じ `openId` で `defaultExpanded` を呼んで、そこに入っている `v:`/`g:`/`f:` を足せば取れる。
- **文言（`components/records.ts`）**: 分子の行 = `node.formula` ＋右に小さく `formulaMeta(node)`
  （`"9"`）。段の行 = `levelHeading(group)`（null の段は `OTHER_LEVEL` ＝「ほかの計算」）＋右に
  `levelMeta(group)`（`"8 · 2 種類の形"`、谷 1 つなら `"8"`）。谷の行 = `head.record.name`・
  `relativeText(head, settledCount(group))`・`valleySizeText(node)`（`"×5"`）。記録の行は今の
  `RecordsPanel` と同じ `relativeText` / `sameShapeText` / `savedAtText`。**`groupHeading` は
  `RecordsPanel` を消したら使い手が無くなる**ので、消すならテスト（`records.test.ts` の
  「the heading of a group」）ごと消す。F4 の検査は `records.test.ts` の「the words of the tree」
  が木の文言を全部集めて見ている（新しい文言を足したらそこに足す）。
