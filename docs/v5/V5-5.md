# V5-5 観察タブの中身（電子の雲・畳める節・詳細）

**依存: V5-3**

**目的**: 観察タブを「計測 → 電子の雲 → 分子軌道（畳む）→ 詳細（畳む）」の並びにし、電子の雲の
ボタンを縦の選択肢にする。π の選択肢が出たり消えたりしても、ほかが動かないようにする。

## 前提

- **電子の雲の選択肢は `Choices`（V5-1、縦に積む）**。各行はラベル＋1 行の説明:
  - `total`「すべての電子」— 分子全体を包む電子の広がり
  - `bonding`「結合に寄与する電子」— **`hasPi` のときだけ**（規約。`offeredChannels(hasPi)`）
  - `deformation`「原子から動いた電子」— 結合で濃く・薄くなったところ
  説明の文言は `components/density.ts` に `CHANNEL_NOTES`（`channelNote(request)`）として足し、
  `density.test.ts` に「基底・汎関数・電荷・多重度の語が出ない」を足す（既にある検査の形に合わせる）。
  **`bonding` の行はいちばん下ではなく 2 番目**（`REQUEST_ORDER` のまま）。縦に積むので、
  増えても上の行は動かない。
- **軌道が出ているあいだはどれも選ばれていない**（今と同じ。`channel` は
  `orbitalPick === null ? densityRequest : 'orbital'`、App.tsx 297 行あたり）。選ぶと
  `selectChannel(request)`（924 行あたり）で密度に戻る。
- 見出しを「電子密度」から**「電子の雲」**に（トグルの「電子の雲を表示する」と揃える）。
  トグルは見出しの行の右に置いてよい。しきい値のスライダーと `explainChannel` の 1 行は今のまま。
- **畳める節の部品**: `components/Fold.tsx`（`<details>` / `<summary>`。閉じているときだけ
  `summary` の右に 1 行の予告を出す）。**`<summary>` の中の見出しは 1 つだけ**
  （V4-4 の決まり。見出しは `<h2>` のまま）。
  - 分子軌道: `OrbitalPanel.tsx` の `<details className="orbitals">` と、閉じているときの
    `ORBITAL_TEASER` を `Fold` に置き換える。`open` / `onOpenChange`（App の `orbitalsOpen`）は
    そのまま渡す。**既定で閉じる。** `scan` の prop はまだ残す（V5-6 で外す）。
  - 詳細: V5-2 で作った `<details>` を `Fold`（予告「反復・計算時間・等値面」）に。
- 計測（`ObservePanel`）は今の中身のまま。「結合の長さをすべて表示」のトグルと「計測を解除」は
  1 行に並べる（`ActionGrid` ではなく、左にトグル・右にボタン）。
