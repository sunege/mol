## v5 で決まっていること（全チケットに効く）

1. **タブ＝モード。** タブは `mode`（`ViewerMode = 'edit' | 'observe'`）から描き、押したら
   `chooseMode`。計算の開始で観察へ、発散・エラー・中止で元へ戻る今の動きがそのまま効く。
   タブ用の状態を別に持たない（狭い画面の「記録」タブだけが例外、V5-10）。
2. **状態・全エネルギー・主ボタン 2 枠はパネルの上に固定**（V5-2）。
3. **記録は左の欄のツリー: 分子 › 段 › 記録。同じ谷は代表 1 件の下に畳む**（V5-7, V5-8）。
   探索の候補も同じツリーに入る（V5-9）。
4. **ボタンは 4 つの型だけ**（V5-1 の `components/controls.tsx`）: `Segmented`（等幅の切り替え）・
   `Choices`（縦の選択肢）・`ActionGrid`（列数固定の格子）・`IconButton`（行の中）。
   **使えないときは消さずに無効にする。** 例外は規約で「出さない」と決めたもの（π の選択肢、
   原子 2 個のときだけの「近づけてみる」）で、縦に積む場所に置く。
5. **パネルの幅は 340px**、左の欄は 236px（畳んで 40px）。
6. **F4 はそのまま。** フォルダの名前は分子式と `levelLabel` だけ。電荷・多重度・基底は出さない。
7. **分子軌道の節は既定で閉じる。** 等値面は常に 1 つ。
8. **アイコンはインライン SVG**（`components/icons.tsx`）。ページは cross-origin isolated なので
   アイコンフォントや CDN は読めない。

理由は [docs/plan-v5.md](../plan-v5.md)、数字は dev-notes「v5-0 の実測」。

## トークンを節約する決まり（全チケット）

v5 は UI だけで、読むものを絞れば 1 セッションが小さく済む。

- **`web/src/App.tsx`（約 2,400 行）を丸ごと読まない。** チケットの「触る場所」にある関数名や
  JSX の目印を `grep -n` で探し、その前後だけ `sed -n` で読む。行番号はチケットを書いた時点の
  目安で、前のチケットでずれている。
- **`App.css`（約 900 行）も丸ごと読まない。** セレクタを `grep -n` で探す。
- **dev-notes と plan-v5.md は読まない**（チケットが節を指したときだけ、その節だけ）。
- **ブラウザでの確認は `read_page` / `javascript_tool` で数値を取る**（高さ・並び・無効かどうか）。
  スクリーンショットは最後の 1 枚だけ。dev サーバーは `preview_start` の `mol-dev`
  （5173 が使用中なら、ユーザーの dev サーバーなので `navigate` で `http://localhost:5173` を開く）。
- **Claude の作業ブラウザは WebGL が使えない**（3D は出ないがパネル・Worker は動く。計算も回る）。
  3D の上に置くもの（V5-4）とクリック操作は **ユーザーに Firefox で見てもらう**（V5-11）。
- **テストは純粋な `.ts` に書く**（vitest は `environment: 'node'`、DOM のテストは無い）。
  `.tsx` は薄くして、文言と並びは `.ts` で決める。
- 検査は `npm test` と `npm run lint --workspace web` と `npm run build`（型）。

## チケットを終えるときにやること

1. **この板の状態を書き換える**（1 行）。
2. **実測・却下した案は dev-notes の「フェーズの記録」に 1 節**足す（「V5-n の実装メモ」）。
   チケット本文には書かない。
3. **後のチケットが頼ることが分かったら、そのチケットに「V5-n で入ったもの」を足す**
   （名前・props・CSS クラス・ずれた目印）。次のセッションはそれしか読まない。
4. **規約が増えたら CLAUDE.md に 1〜2 行**。増えていないなら触らない。
5. コミットはユーザーに言われたときだけ。

## 全チケットに共通する前提

- 画面は暗い配色だけ（`index.css` の `color-scheme: dark`）。色は今の `App.css` の値を使う:
  地 `#0e1116`、パネル `#151a21`、線 `#262d38`、ボタン `#1c222c` / 枠 `#2d3644`、
  文字 `#d6dde8`、弱い文字 `#7c8798`、強調 `#3f8cff` / 選択の地 `#1d3a66`。
- **Viewer は `ResizeObserver` で自分の大きさを追う**（`scene/viewer.ts` の `#resize`）ので、
  左の欄を畳んでも 3D の側は何もしなくてよい。`renderer.setSize` の第 3 引数は触らない。
- 測定ラベルの層は `z-index: 1`、進捗カードは `2`（`App.css` の `.viewer-labels` /
  `.progress-card`）。3D の上に足すものはこの間に割り込ませない。
