# V5-1 ボタンの型をそろえる（部品と CSS）

**依存: なし**

**目的**: ボタンの並びが画面や状態で揺れないようにする。**配置はまだ変えない**（今の並びのまま
部品を置き換える）。後のチケットはすべてこの部品で組む。

## 前提

- 揺れの原因（dev-notes「v5-0 の実測」）: どの行も `.row`（`display: flex; flex-wrap: wrap`、
  ボタンは内容幅）なので、ラベルの長さで 1 行にも 2 行にもなる。ボタンの CSS は
  `.row button` / `.mode-switch button` / `.level-switch button` / `.record-actions button` /
  `.candidate-actions button` / `.file-button` の 6 種類。
- **型は 4 つだけ**（板の決定 4）。どれも CSS grid で列数を先に決め、ラベルは
  `white-space: nowrap; overflow: hidden; text-overflow: ellipsis` で枠からはみ出さない。
  1. `Segmented` — どれか 1 つを選ぶ。等幅、折り返さない。`aria-pressed`。
  2. `Choices` — 縦に積む選択肢（ラベル＋任意の 1 行の説明）。`role="radiogroup"` と
     `role="radio"` / `aria-checked`。**V5-5 で電子の雲に使う**（ここでは作るだけ）。
  3. `ActionGrid` — `columns: 2 | 3 | 5` の格子。中身は普通の `<button>`。
  4. `IconButton` — 26px 四方、`aria-label` と `title` が必須。
- ボタンの見た目は 1 つのクラス `.btn`（今の `.row button` の値: padding 6px 10px、
  0.85rem、角丸 6px、枠 `#2d3644`、地 `#1c222c`、hover で枠 `#3f8cff`、disabled で
  opacity 0.4、`.active` で地 `#1d3a66`・枠 `#3f8cff`）＋小さい版 `.btn.small`（2 段だけ）。
  主ボタンは `.btn.primary`（今の「安定な形にする」の `active` と同じ見た目）。
- アイコンは `components/icons.tsx` にインライン SVG で置く（16×16 の viewBox、
  `stroke="currentColor"`）。V5-4・V5-8・V5-9 が使う: 全体表示・再生・名前・削除・中止・
  「…」・畳む/開く（くの字）。

## 触る場所

- **新規** `web/src/components/controls.tsx`（4 つの部品）と `web/src/components/icons.tsx`。
- `web/src/App.css`: `.row button` の塊（`grep -n "^\.row" App.css`、88〜116 行あたり）を
  `.btn` に置き換え、`.seg` / `.choices` / `.action-grid` / `.icon-btn` を足す。
  `.mode-switch` / `.level-switch` の塊（`grep -n "mode-switch\|level-switch" App.css`）は
  `Segmented` が肩代わりするので消す。**`.record-actions` / `.candidate-actions` /
  `.file-button` は触らない**（V5-8・V5-9 で部品ごと消える）。
- `web/src/App.css` の `.app` の `grid-template-columns: 1fr 300px` を **`1fr 340px`** に。
- `web/src/App.tsx` の JSX（`grep -n "return (" App.tsx` の最後、1902 行あたりから）で次だけ:
  - `className="row mode-switch"`（1939 行あたり）→ `Segmented`。
  - 編集の 3 つ（`onClick={deleteSelected}`、1970 行あたり）→ `ActionGrid columns={3}`。
    「削除（O）」のように元素名が入るラベルは**「削除」に固定**（何を消すかは 3D の選択で見える）。
  - プリセット（`PRESETS.map`、2000 行あたり）→ `ActionGrid columns={5}`。
  - 段（`className="row level-switch"`、2022 行あたり）→ `Segmented`。
  - 計算の 2 つ（`onClick={computing ? stopCalculation : relax}`、2044 行あたり）→
    `ActionGrid columns={2}`。ラベルの切り替えは今のまま（固定の 2 枠にするのは V5-2）。
  - 電子密度のボタン（`offered.map`）→ **今は `ActionGrid columns={2}` で包むだけ**
    （縦の選択肢にするのは V5-5）。
- `web/src/components/SearchPanel.tsx` の 2 つのボタンの `.row` → `ActionGrid columns={2}`。
  一覧の部分は触らない（V5-9 で消える）。
- `RecordsPanel.tsx` / `DistanceScan.tsx` / `ObservePanel.tsx` の `.row` は**触らない**
  （それぞれ V5-8・V5-6・V5-5 で置き換わる）。`.btn` を当てるのは `.row button` の CSS を
  消したときに見た目が崩れる所だけ（`className="row"` の中の `<button>` に `className="btn"`
  を足す、の最小限でよい）。

## やること

1. `icons.tsx` と `controls.tsx` を書く。部品は props だけで動く薄いもの（状態を持たない）。
2. CSS を置き換える。
3. App と SearchPanel の上の箇所を部品に置き換える。

## 完了条件

- `npm test`・`npm run lint --workspace web`・`npm run build`。
- Claude のブラウザ（1366×768）で `javascript_tool` を使い、パネルの中の**格子の行が
  どれも 1 行の高さ**であること（`ActionGrid` / `Segmented` の `getBoundingClientRect().height`
  がボタン 1 つ分）。O₂ と C₆H₆ のプリセットを押し比べても、編集・計算の行の高さと
  ボタンの x 座標が変わらないこと。
