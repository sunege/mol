# V5-6 「近づけてみる」を分子軌道から分ける

**依存: V5-5**

**目的**: 距離スキャンと相関図（`DistanceScan`）を「分子軌道」の節の中から出して、観察タブの
別の畳める節「近づけてみる」にする。今は分子軌道を開くと、はしご＋相関図＋スキャンで約 1,300px。

## 前提

- `DistanceScan` は今 `OrbitalPanel` の `scan` prop として渡されている（App.tsx、
  `grep -n "<DistanceScan" App.tsx`、`atoms.length === 2 ? (...) : null`）。**原子がちょうど
  2 個のときだけ**節ごと出す（規約）。
- **取りに行く条件がいま `orbitalsOpen` に結びついている。ここがこのチケットの本体。**
  新しく `scanOpen`（`useState(false)`）を持ち、次の 3 か所を直す:
  1. **原子の準位**（`client.atomLevels(...)`、`grep -n "atomLevels(" App.tsx`、1086 行あたり）:
     条件 `!orbitalsOpen` → **`!scanOpen`**。依存も `[scanOpen, scanPairKey]`。
     相関図の左右の列で、使うのは近づけてみるだけ。
  2. **軌道の一覧**（`client.orbitals()`、989 行あたり）: 相関図の真ん中の列に要る。条件を
     **`!(orbitalsOpen || scanOpen)`** にする。**危険**: この effect は先頭で `forgetOrbital()` を
     呼ぶので、`scanOpen` を依存に足すと**近づけてみるを開閉するたびに選んでいた軌道が消える**。
     依存には `orbitalsOpen || scanOpen` を 1 つの値（`const wantLevels = ...`）として入れ、
     分子軌道を開いたまま近づけてみるを開いても値が変わらないようにする。**分子軌道の節を
     閉じたら軌道を捨てる**今の決まり（コメント「Closing the section drops it too」）は残す:
     `forgetOrbital()` を `!orbitalsOpen` のときにも呼ぶ形に分ける。
  3. **重なり（`orbitalWeights`）**（1115 行あたり）: `orbitalLevels` と `atomCount === 2` しか
     見ていないので、そのままで動く。
  - `orbitalBonds` / `orbitalSymbols`（1866 行あたり）は分子軌道の節の言葉のためなので
    `orbitalsOpen` のまま。
- スキャンは計算していなくても動く（自分で幾何を解く）ので、節は計算の前でも開ける。
  相関図の真ん中の列は計算の後（`hasDensityRef` かつ `resultLevel === 'shape'`）にだけ出る
  ＝ 今と同じ。
- 予告の 1 行は「2 つの原子の距離を変えて、部屋の高さを見る」程度（`components/scan.ts` に
  `SCAN_TEASER` として置く。`scan.test.ts` の「数字が横軸の距離だけ」の検査に入れる）。
- **スキャンの組のボタン**（`DistanceScan.tsx` の `className="row scan-pairs"`、H₂・He₂・N₂・
  O₂・HF・いまの 2 原子）を `ActionGrid columns={3}` に、「スキャンする／この距離で計算」
  （その下の `.row`）を `ActionGrid columns={2}` に。V5-1 で残した `.row` はここで消える。

## 触る場所

- `App.tsx`: `scanOpen` と上の 2 つの effect。`<DistanceScan>` を `OrbitalPanel` の `scan` から
  外し、観察タブの分子軌道の後ろに `Fold`（V5-5）で置く。
- `components/OrbitalPanel.tsx`: `scan` prop と `{scan}` を消す。
- `components/DistanceScan.tsx`: ボタンの 2 行。
- `components/scan.ts`（＋テスト）: 予告の文言。

## 完了条件

- `npm test`・`npm run lint --workspace web`・`npm run build`。
- Claude のブラウザ（観察タブ、O₂ のプリセット）:
  - 計算の前に「近づけてみる」だけを開いてスキャンが走り、図が出る（分子軌道は閉じたまま）。
  - 計算の後、分子軌道で段を 1 つ選んでから近づけてみるを開閉しても、**選んだ段が消えない**。
  - 分子軌道を閉じると選んだ段が消える（今と同じ）。
  - H₂O（3 原子）では近づけてみるの節が無い。
- Worker の往復が増えていないこと（`read_network_requests` は使えないので、dev の
  `console.debug` か、effect の中に一時的な数え上げを置いて確かめ、消す）。

## V5-1 で入ったもの

- `components/controls.tsx`: `Segmented<T>({ label, options: { value, label, title? }[], value,
  onChange, disabled?, small? })`・`Choices<T>({ label, options: { value, label, description? }[],
  value: T | null, onChange, disabled? })`・`ActionGrid({ columns: 2 | 3 | 5, label?, children })`・
  `IconButton({ label, onClick, disabled?, active?, children })`。**`ActionGrid` の中のボタンは
  自分で `className="btn"`**（`primary` / `active` も足す）。
- CSS: `.btn`（`.small` / `.primary` / `.active`）・`.seg`・`.choices`（`.btn.choice` /
  `.choice-label` / `.choice-description`）・`.action-grid.cols-N`・`.icon-btn`。
  **`.row button` の CSS は無い**（`.row` は隙間だけの flex）。`.mode-switch` / `.level-switch` も無い。
- `DistanceScan.tsx` の `.row scan-pairs` と `.row` はそのままで、ボタンに `btn`（選ばれたものは
  `btn active`）を足しただけ。

## V5-5 で入ったもの

- **`components/Fold.tsx`**: `<Fold heading teaser className? open? onOpenChange?>…</Fold>`。
  `open` を渡すと制御、渡さないと自前の状態（既定は閉）。予告は閉じているときだけ見出しの右に
  1 行（`.fold-teaser`、はみ出すと省略記号）。**予告は 14 字前後まで**（340px のパネルで
  「分子軌道」の右に入るのは 20 字弱）。開閉の印は CSS の `::before`（▸／▾）。
- `OrbitalPanel` は**丸ごと `<Fold className="orbitals" …>` を返す**（外側の `<>` も予告の
  `<p>` も無い）。中身の最後がまだ `{scan}`。`ORBITAL_TEASER` は「電子の「部屋」を形と色で見る」。
- 観察タブの並び: `<ObservePanel` → `.section-head`（`<h2>電子の雲</h2>` とトグル）→ `<Choices`
  → `IsoLevelSlider` → `explainChannel` の `.hint` → `<OrbitalPanel` → `<Fold heading="詳細"
  … className="details">`。近づけてみるの `Fold` は `OrbitalPanel` と詳細の間に入る。
