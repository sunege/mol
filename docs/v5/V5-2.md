# V5-2 状態と主ボタンをパネルの上に固定する

**依存: V5-1**

**目的**: 「計算は終わったか・エネルギーはいくつか」と「止める」が、パネルをどこまで
スクロールしていても見えて押せるようにする。今は状態の一覧がパネルの最下部（O₂ で分子軌道を
開くと 3,000px 下）にある。

## 前提

- **パネルを縦の flex にする**: 上に固定のヘッダー（スクロールしない）、下にスクロールする本体。
  `position: sticky` ではなく、`.panel` を `display: flex; flex-direction: column` にして本体だけ
  `overflow-y: auto` にする（V5-3 でタブの帯がヘッダーと本体の間に入る）。
- **ヘッダーに置くもの**: 題（`分子シミュレータ`、小さく 1 行）、状態・形の調整・全エネルギーの
  3 行、主ボタン 2 枠（`ActionGrid columns={2}`）。
- **主ボタンは固定の 2 枠で、ラベルと働きだけが変わる**:

  | 状態 | 左の枠 | 右の枠 |
  | --- | --- | --- |
  | 計算していない | **安定な形にする**（`relax`、primary） | この形のまま計算（`calculate()`） |
  | 計算中 | **中止**（`stopCalculation`） | この形のまま計算（無効） |
  | 止めている途中（`job.stopping`） | 止めています…（無効） | **すぐ止める**（`stopCalculation`） |

  `stopCalculation` は 1 度目が「一歩の後で止める」、2 度目が即止め（`stopRelaxations(true)`）で、
  一点計算なら `cancelCalculation`。**働きは今と同じで、並べ方だけが変わる**。無効の条件も今と
  同じ（エンジンが無い・原子が 0 個）。
- **この表は純粋な関数にする**: `components/actions.ts` の
  `actionSlots({ computing, stopping, unavailable, atomCount })` → 2 つの
  `{ label, action: 'relax' | 'calculate' | 'stop', disabled, primary }`。App は `action` を
  関数に写すだけ。テストは `actions.test.ts` で上の 3 行と無効の条件。
- **ボタンの下の説明文**（今は 3 通り、2057 行あたりの `<p className="hint">`）:
  - 止めている途中 → **要らない**（`headline(job)` が「止めています · いまの一歩が終わるまで」と
    状態の行に出し、右の枠が「すぐ止める」になる）。
  - 途中までの形（`relaxation.reason !== 'converged'` または `stopped !== null`）→ ヘッダーに
    **1 行だけ**「もう一度「安定な形にする」を押すと、ここから続きを計算します。」
  - 既定の長い説明 → ヘッダーから外して、本体の段の選択の下に残す（V5-3 で計算タブへ行く）。
- **最下部の `<dl>`**（`grep -n "<dl>" App.tsx`、2182 行あたり）を分ける:
  - 状態・形の調整・全エネルギー → ヘッダーへ。**状態の文言の分岐はそのまま移す**（F5: 発散は
    `—`、`solved` と `settled` の区別、`stopped` の扱い）。
  - 反復・計算時間・等値面・WebGL → 本体のいちばん下の**既定で閉じた `<details>`「詳細」**へ
    （V5-5 で観察タブの畳める節に揃える）。
  - 原子数 → **なくす**。
- `describeRelaxation` / `describeMesh`（App.tsx の末尾、`grep -n "^function describe"`）は
  **`components/status.ts` へ移してテストを付ける**（`status.test.ts`。`'converged'` で 0 歩と
  n 歩、`'interrupted'`、`'maxSteps'`、`stopped` あり、非収束で `—`）。App.tsx が 2 関数ぶん短くなる。
- 計算中の状態の行は `headline(job)` と `<Elapsed since={job.startedAt} />`
  （`components/ProgressOverlay.tsx` から import 済み）。

## 触る場所

- **新規** `components/actions.ts`（＋テスト）、`components/status.ts`（＋テスト）、
  `components/StatusHeader.tsx`（状態の 3 行＋2 枠。props で受ける）。
- `App.tsx`: `<aside className="panel">` の直下（1935 行あたり）にヘッダーを置き、今の
  「計算」の 2 ボタンと説明文、最下部の `<dl>` を外す。
- `App.css`: `.panel` を flex の縦に、`.panel-head`（下に `#262d38` の線）と `.panel-body`
  （`overflow-y: auto`）。720px 以下の `@media` の `.panel { max-height: 50vh }` はそのまま
  （狭い画面は V5-10）。

## 完了条件

- `npm test`・`npm run lint --workspace web`・`npm run build`。
- Claude のブラウザ（1366×768）: H₂O で「安定な形にする」→ 計算中に本体を下までスクロールしても
  ヘッダーの「中止」が見えていて押せること（`javascript_tool` で `getBoundingClientRect().top`
  がヘッダーの中）。C₆H₆ で「安定な形にする」→「中止」→ 右の枠が「すぐ止める」になり、押すと
  止まること。2 枠の x 座標と幅が、どの状態でも同じこと。
- 「詳細」が閉じた状態で本体の最下部にあり、開くと反復・計算時間・等値面・WebGL が出ること。
