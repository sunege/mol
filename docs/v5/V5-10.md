# V5-10 狭い画面（下からのシートと 3 タブ）

**依存: V5-5, V5-8**

**目的**: 幅 720px 以下で、左の欄が置けない画面でも記録に届くようにする。パネルを下からの
シートにし、「計算・観察・記録」の 3 タブにする。

## 前提

- 今の 720px 以下（`App.css` の `@media (max-width: 720px)`）: `.app` が 1 列・2 行、
  `.panel` が下で `max-height: 50vh`。V5-8 で左の欄は `display: none` にしてある。
- **3 枚めの「記録」タブは狭い画面だけ。** 選ばれているタブは `mode` から描く（板の決定 1）が、
  「記録」を選んだときだけは**モードを変えずに**中身を記録に差し替える。状態は App に
  `narrowRecords: boolean` を 1 つだけ持つ（計算／観察のタブを押したら false）。
  **計算が始まって観察に移るとき（`observeWhileRunning`）も false にする**（中止が見えるように。
  ヘッダーは固定なので見えてはいるが、結果を見せる）。
- 狭いかどうかは `matchMedia('(max-width: 720px)')` を `useSyncExternalStore` で読む
  （`components/useNarrow.ts`）。CSS の境と同じ 720px。
- **記録タブの中身は `RecordExplorer` をそのまま**（畳むボタンだけ隠す）。同じ部品を 2 か所に
  描かない: 広い画面では左の列、狭い画面ではシートの中、のどちらか 1 つ。
- シートの高さは今の 50vh のまま。ヘッダー（状態と主ボタン）とタブの帯は固定、本体だけ
  スクロール（V5-2 の flex がそのまま効く）。
- 3D の上の帯とアイコン（V5-4）は 3D の列の中なので、狭くてもそのまま。帯の文言が 1 行に
  収まらないときは折り返してよい（`white-space: normal`、最大 2 行）。

## 触る場所

- **新規** `components/useNarrow.ts`。
- `components/Tabs.tsx`: 狭いときだけ 3 つめ。
- `App.tsx`: `narrowRecords` と、`RecordExplorer` をどこに描くかの分岐。
- `App.css`: `@media (max-width: 720px)` の中。

## 完了条件

- `npm test`・`npm run lint --workspace web`・`npm run build`。
- Claude のブラウザで `resize_window` の `mobile`（375×812）→ 再読み込み:

  「安定な形にする」で観察タブに移る。**終わったら `resize_window` を `desktop` に戻す。**
- 1366×768 に戻して、左の欄とタブ 2 つに戻ること（記録が 2 か所に出ていないこと）。

## V5-1 で入ったもの

- `components/controls.tsx`: `Segmented<T>({ label, options: { value, label, title? }[], value,
  onChange, disabled?, small? })`・`Choices<T>({ label, options: { value, label, description? }[],
  value: T | null, onChange, disabled? })`・`ActionGrid({ columns: 2 | 3 | 5, label?, children })`・
  `IconButton({ label, onClick, disabled?, active?, children })`。**`ActionGrid` の中のボタンは
  自分で `className="btn"`**（`primary` / `active` も足す）。
- CSS: `.btn`（`.small` / `.primary` / `.active`）・`.seg`・`.choices`（`.btn.choice` /
  `.choice-label` / `.choice-description`）・`.action-grid.cols-N`・`.icon-btn`。
  **`.row button` の CSS は無い**（`.row` は隙間だけの flex）。`.mode-switch` / `.level-switch` も無い。
- パネルは `.app` の `grid-template-columns: 1fr 340px`。`Segmented` の列数は選択肢の数から
  inline の `gridTemplateColumns` で決まるので、3 タブにしても CSS は要らない。

## V5-2 で入ったもの

- `.panel` は縦の flex（`overflow: hidden`）で、`.panel-head`（`flex: none`）と
  `.panel-body`（`overflow-y: auto`、`min-height: 0`）。720px 以下の `.panel { max-height: 50vh }`
  はそのままで、本体だけがスクロールする。ヘッダーは 1366×768 で 167〜212px（状態の行の折れ方
  次第）なので、狭い画面のシートではこの高さが効く。

## V5-4 で入ったもの

- 帯は `.viewport` の中の `<p className="viewport-hint">`（`App.css` の `.viewport-hint`: 下端中央、
  `white-space: nowrap` + `text-overflow: ellipsis`、`max-width: calc(100% - 120px)`、
  `pointer-events: none`、`z-index: 1`）。2 行にするならここの `white-space` と `overflow` を
  狭い画面のときだけ変える。出るのは WebGL が動いているときだけ。
- 右下の `.viewport-tools`（`right: 12px; bottom: 10px`、`z-index: 2`）に 32px の `IconButton`
  （全体表示）が 1 つ。

## V5-6 で入ったもの

- 観察タブの節は **分子軌道 → 近づけてみる → 詳細**（近づけてみるは原子がちょうど 2 個のときだけ）。
  近づけてみるは `<Fold heading={SCAN_HEADING} …>` の中に `DistanceScan`（`section.scan`）で、
  ボタンは `ActionGrid` の 3 列（組 6 つ）と 2 列。SVG は 260 単位の viewBox で幅に従う。
  O₂ で開くと節だけで約 900px（1024×768）なので、シートの中はスクロールが前提。

## V5-5 で入ったもの

- 観察タブ（1366×768）のタブパネルは H₂O で 464px、C₆H₆ で 518px（分子軌道・詳細は閉）。
  電子の雲は `Choices`（1 行 49px の縦積み）、畳める節は `components/Fold.tsx`（`.fold`）、

## V5-8 で入ったもの

- **欄は `components/RecordExplorer.tsx`**、App では `.app` の最初の子（`grep -n "<RecordExplorer" App.tsx`、
  `<div className="viewport"` の前）。**グリッドは `grid-template-columns: auto 1fr 340px`**（変数では
  ない。欄が自分で `width: 236px`、畳むと `.explorer.collapsed` で 40px）。シートの中に置くなら
  `width: auto` にする。
- **狭い画面で欄を隠しているのは `App.css` の末尾の別の `@media (max-width: 720px) { .explorer {
  display: none } }`**（既存の 720px の塊の中ではない。前に書くと後ろの `.explorer { display: flex }`
  に負ける）。シートに描くなら、ここを左の列の欄だけ（例えば `.app > .explorer`）に絞る。
- **畳むボタンは `.explorer-head` の `IconButton`**（ラベル `EXPLORER_WORDS.fold`）で、隠す props は
  まだ無い（`foldable?: boolean` などを足す）。**覚えた `collapsed` が真だと欄は帯だけを描く**
  （`if (memory.collapsed)` の枝）ので、シートの中ではそれを無視すること。
- 開閉と畳みの記憶は `localStorage` の `mol.explorer`（`components/explorer.ts`）。左の列と
  シートは同時には描かないので、同じ記憶を共有してよい。
- 欄の中でスクロールするのは `.explorer-tree` だけ（`flex: 1; min-height: 0; overflow-y: auto`）。
  下端の `.explorer-caveat`（`ISOMER_CAVEAT`）は常に出る。

## V5-9 で入ったもの

- **`RecordExplorer` の props が増えた**: `candidates` / `symbolOf` / `onOpenCandidate` /
  `onCancel` / `onCancelAll` / `onClearFinished`（App の `<RecordExplorer` にある。シートに描くときも
  同じ props をそのまま渡す）。候補の時計（`components/useNow.ts`）は欄の中で回るので、
  **狭い画面で「記録」タブを開いていないあいだは候補の行も時計も描かれない**（計算タブの
  `.search-summary` の 1 行だけが見える）。それで困らないが、「記録」タブに回転の印を出すなら
  `candidates.some(canCancel)`（`components/search.ts`）で判定できる。
- 欄の中の `.spinner`（回転の印）は見出しの行（`.explorer-head`）と畳んだ帯の 2 か所。
  シートの中で畳むボタンを隠すなら、見出しの行の印はそのまま残る。
