# V5-4 操作の説明と「全体表示」を 3D の上へ

**依存: V5-3**

**目的**: パネルから長い操作の説明と、2 か所にある「全体表示」を外す。説明は今のタブ（＝モード）に
合わせて 3D 画面の下端に 1 行、「全体表示」は 3D 画面の右下のアイコン 1 つにする。

## 前提

- 今の説明文（どちらもパネルの `.hint`）:
  - 編集: 「何もない場所をクリックで配置 · 原子をドラッグで移動 · 原子を Shift+クリックで
    結合距離に隣接配置 · 背景をドラッグで回転」（App.tsx、`grep -n "何もない場所" App.tsx`）
  - 観測: 「原子をクリックで選ぶ · もう一度クリックで外す · ドラッグで回転 · Esc で計測を解除」
    （`ObservePanel.tsx` の最後の `<p className="hint">`）
  - **ObservePanel の `pickingHint(symbols.length)` は選んだ数で変わる案内なので、パネルに残す。**
- **文言は純粋な関数に**: `components/viewportHint.ts` の `viewportHint(mode, atomCount)`。
  原子が 0 個の編集では「何もない場所をクリックすると原子を置けます。プリセットからも始められます。」
  のような始め方の 1 行、それ以外は上の 2 文を短くしたもの。テストは `viewportHint.test.ts`
  （2 モード × 0 個／1 個以上、どれも 1 行＝改行を含まない）。
- **置き方**: `.viewport` の中、下端中央に `pointer-events: none` の帯。
  **`z-index` は測定ラベル（1）と進捗カード（2）の間に割り込ませない**: 帯は `z-index: 1` 以下で、
  進捗カード（左上）とも重ならない位置（下端）。WebGL もエンジンも無いとき（`.webgl-error` /
  `.engine-unavailable` が出ているとき）は出さない。
- **「全体表示」**: `IconButton`（V5-1 の `icons.tsx` の全体表示）を `.viewport` の右下に。
  押すと `viewerRef.current?.frameAll()`、原子が 0 個なら無効。**これは pointer を受ける**ので
  `z-index: 2` 以上でよいが、進捗カード（左上）とは離れている。
  パネル側の 2 つ（編集の格子と `ObservePanel` の `onFrame`）は消す。ObservePanel の props から
  `onFrame` / `canFrame` を外す。編集の格子は「削除」「全消去」の 2 列になる（`columns={2}`）。

## 触る場所

- **新規** `components/viewportHint.ts`（＋テスト）。
- `App.tsx`: `.viewport` の中（`<ProgressOverlay` の近く、1925 行あたり）に帯とアイコン。
  編集の説明文と「全体表示」ボタンを消す。
- `ObservePanel.tsx`: 最後の説明文と「全体表示」を消す。
- `App.css`: `.viewport-hint` / `.viewport-tools`。

## 完了条件

- `npm test`・`npm run lint --workspace web`・`npm run build`。
- Claude のブラウザ: 帯の文言がタブで切り替わること、原子 0 個で始め方の 1 行になること、
  アイコンの `aria-label` が「全体表示」で、原子 0 個で無効なこと（`read_page`）。
  **WebGL が無いのでこのブラウザでは帯が出ない方が正しい**（`.webgl-error` のとき出さない）。
  確かめるときは一時的に条件を外すか、`javascript_tool` で DOM に帯が無いことを見る。
- **見た目とクリックが通るか（帯の上で原子を置ける・回せる）はユーザーに Firefox で**（V5-11）。
