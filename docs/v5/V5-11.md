# V5-11 ユーザーの確認（Firefox・講義 PC）

**依存: 全部**

**目的**: Claude の作業ブラウザでは見られないもの（3D の上の帯とアイコン、3D のクリックとタブの
対応、見た目の揺れ）をユーザーに見てもらい、1366×768 でスクロールせずに届くかを前後で比べる。

## 前提

- v5 の前の数字（dev-notes「v5-0 の実測」、1366×768）: H₂O を計算した直後でパネルの
  `scrollHeight` 2,168px、O₂ で分子軌道を開いて 3,055px。状態と全エネルギーはその最下部。
- V5-3・V5-5 の実装メモに、タブごとの本体の高さが残っているはず。

## やること

1. **Claude が測る**（1366×768、Browser）: 計算タブと観察タブ（分子軌道・近づけてみる・詳細は
   閉じた状態）の本体の `scrollHeight`、ヘッダーの高さ、左の欄の幅。H₂O と O₂ で。
   dev-notes に「v5 の実測」として前後の表を足す。
2. **ユーザーに Firefox で見てもらう項目**を 1 つのリストにして渡す:
   - 計算タブで原子を置ける・観察タブで原子を測れる（タブとクリックが一致）。
   - 「安定な形にする」で観察タブに移り、中止・発散で元のタブに戻る。
   - 3D の下端の帯が読めて、その上で原子を置ける・回せる（帯がクリックを奪わない）。
   - 右下の「全体表示」。測定ラベル・進捗カードと重ならない。
   - ボタンの並び: C₆H₆ で「中止」→「すぐ止める」でも枠が動かない。π の選択肢が出ても
     「すべての電子」の位置が変わらない。
   - 記録: 同じ谷が畳まれている。畳む・開く・再読み込み。記録を開いて観察タブを見られる。
   - 探索: 候補が左に出て、終わると記録になる。
   - 狭い画面（ウィンドウを細くする）で 3 タブ。
3. **講義 PC**（Windows 11 / Chrome、1366×768 か 1920×1080）で同じ項目のうち、見た目と
   スクロール量だけ。
4. 指摘を直す（小さければこのチケットで、大きければ板に足す）。
5. **CLAUDE.md を v5 の状態に**: 「状態と今後」に v5 の 2〜3 行、「UI」の規約に
   タブ＝モード・ボタンの 4 つの型・記録は左の欄（狭い画面だけタブ）を 1〜2 行ずつ。
   冒頭の「次にやるのは」を書き換える。

## 完了条件

- ユーザーの Firefox と講義 PC の確認が済み、dev-notes にその節と太字の締めの 1 行。
- 板の全チケットが完了。

## V5-4 で入ったもの

- 下端中央の帯（`.viewport-hint`）はタブで文言が変わる（計算: 「クリックで配置 · …」、観察:
  「クリックで選ぶ · …」、原子 0 個ではどちらも始め方の 1 行）。**帯の上でも原子を置けて、回せること**
  （`pointer-events: none`）。帯は Claude のブラウザ（WebGL 無し）では出ないので、ここで初めて見る。
- 右下の「全体表示」アイコンは原子 0 個で無効。押すと分子が画面に収まる。

## V5-5 で入ったもの

- 分子軌道と詳細は `Fold`（`summary` が flex で、開閉の印 ▸／▾ は CSS の `::before`）。
  **Firefox で印が二重にならない・消えないこと**、閉じているときの予告が見出しの右の 1 行に
  収まること。
- 電子の雲は縦の選択肢（ラベル＋1 行の説明）。「すべての電子」の y は H₂O と C₆H₆ で同じ
  （本体の上から 241px、Claude のブラウザ）。

## V5-6 で入ったもの

- Firefox の確認に足す項目: O₂ で「近づけてみる」を計算前に開いてスキャンが走る／分子軌道で
  段を選んでから近づけてみるを開閉しても段が残る／分子軌道を閉じると段が外れる／H₂O では節が無い
  （いずれも Claude のブラウザでは確認済み。Firefox では見た目とクリックだけ）。
- 観察タブの節は分子軌道・近づけてみる・詳細の 3 つ（`scrollHeight` を測るときはどれも閉じる）。

## V5-8 で入ったもの

- 記録は左の欄（236px、畳んで 40px）。Claude のブラウザで見たのは幅・畳み・再読み込み・木の並び・
  開く・名前・2 つの「…」まで（dev-notes「V5-8 の実装メモ」）。**Firefox で見てほしいもの**:
  欄を畳む／開くで 3D が歪まずに広がる・縮む（`ResizeObserver`）、記録を開いて 3D が変わる、
  「…」の一覧が外を押すと閉じる、名前の欄で Enter / Esc、「読み込む」に Tab で届く。

## V5-9 で入ったもの

- 探索の候補は左の欄の木の中: 分子 › 形を探す の**先頭**に「候補 n」と状態（順番待ち・計算中は
  回転の印と行の中止ボタン、解けなかった候補は `—` で押すと発散、中止した候補は薄い色）。
  終わって記録になると候補の行は消えて記録の行（谷）に入る。記録の無い分子を試すと木の先頭に
  その分子ができる。欄の「…」に「すべて中止」「終わった候補を消す」。欄を畳むとバッジの横に
  回転の印。**Firefox で見てほしいこと**: 回転の印が回っていること、計算中の行の 2 行の折り返しが
  読めること、行の中止ボタンが効くこと。
- 計算タブの探索の節は見出し・ボタン 2 つ・要約 1 行・説明 1 文（1366×768 で 105px）。

## V5-10 で入ったもの

- 幅 720px 以下（`useNarrow`）ではパネルが下のシート（50vh）で、タブは「計算・観察・記録」の 3 つ。
  **左の欄は描かれず、記録タブの中に同じ `RecordExplorer` が 1 つだけ**（畳むボタンなし、
  本体ごとスクロール）。記録タブを選んでもモードは変わらず、計算／観察を押すか計算が始まると
  記録タブは閉じる。候補が回っているあいだ記録タブの見出しに回転の印。記録を開いてもタブは
  記録のまま（下のモードは観察になる。観察タブを押すとその記録が見える）。
- **Firefox で見てほしいこと**（ウィンドウを 720px 以下に細くする）: 3 タブの副題が切れない、
  3D の下端の帯が 2 行まで折り返して読める（Claude のブラウザでは WebGL が無く見ていない）、
  記録タブで木がスクロールして注意書きが最下部にある、記録タブのまま 3D をクリックすると
  そのときのモード（計算なら置く、観察なら測る）で動く、幅を 720px の前後で行き来しても欄が
  2 か所に出ない。
