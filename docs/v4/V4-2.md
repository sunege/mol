# V4-2 エンジンが軌道について答えられるようにする（Rust）

**依存: なし**

**目的**: `dft-core` が「軌道の一覧」と「1 本の軌道を表示用の格子の上で評価したもの」を
返せるようにする。**wasm も UI もまだ触らない**（V4-3 で通す）。

## 前提（これだけ知っていれば着手できる）

- **材料は全部そろっている**: `ScfResult::channels[]` が `energies` / `coefficients`（1 列 1 軌道）/
  `occupations` を持ち（`crates/dft-core/src/scf/mod.rs`）、`System` が `basis` と `overlap` を持つ。
  restricted は 1 組、unrestricted は α と β の 2 組。
- **`density::evaluate` は `D·φ` の二次形式。** rank-1 の `c cᵀ` を流すと **ψ² になって位相が消える**
  ので、線形の評価を別に足すこと。128 点ブロックの作りはそのまま真似る（規約: グリッド点の
  128 点ブロックは性能の前提）。
- **鏡映パリティは空の軌道にもそのまま効く**（`bonding::mirror_parities`。実測で確認済み:
  ベンゼンは占有の 16・19・20 と空の 21・22・23 がパリティ −1 ＝ π 3 本と π\* 3 本）。
  平面の検出は `bonding::molecular_plane`（4 原子未満と非平面は `None`）。
- **縮退はそのまま出てくる。** ベンゼンの 19/20（HOMO）と 21/22（LUMO）は同じエネルギーで、
  Jacobi が返す 2 本は縮退部分空間の中の任意の回転（20 の C1–C2 重なり占有数はちょうど 0、
  19 は +0.1225）。**しきい値 1e-4 Ha で切れる**: 本当の縮退は差が 1e-5 以下、いちばん近い
  別物どうしは 0.026 Ha。
- **固有ベクトルの全体符号は任意**なので、決めないと再計算のたびに位相の色が入れ替わる。
- **開殻も扱う**（plan-v4.md の決定 9）。`ScfResult::channels` は restricted なら 1 組、
  unrestricted なら α・β の 2 組。**畳まずに 2 組のまま返す。**
  実測（O₂、STO-3G/LDA、三重項、0.08 秒、⟨S²⟩ = 2.0002）: α は 9 本、β は 7 本占有で、
  **α の 7・8（縮退、O–O の重なり占有数 −0.1796 ＝ π\*）が埋まり、β の 7・8 は空**。
  **α と β は添字では対応しない**（O₂ で 4→5、5→6、6→4 と入れ替わる）。対応は同じ幾何・同じ
  基底なので**行列積 `C_αᵀ S C_β` 1 回**で出る（最大の絶対値が 0.987〜1.000）。
- 実測（dev-notes「v4-0 の実測」）: 軌道 1 本の評価はベンゼンで 0.256 秒、全電子密度は 0.334 秒。
- 規約: **`dft-core` に wasm 依存も時計も入れない。** 参照値を記憶から書かない。
  `nalgebra` の `SymmetricEigen` は使わない。

## やること

1. **`density::evaluate_orbital(basis, coefficients: &[f64], spec) -> DensityGrid`**。
   `evaluate` と同じブロックの作りで、内側が `Σ_μ c_μ φ_μ` になるだけ。符号付き。
   `DensityGrid` の doc コメントに「同じ型で軌道の振幅も運ぶ（単位は電子/Bohr³ ではない）」を
   1 行足す。
2. **`crates/dft-core/src/orbital.rs`（新規）**:
   - `pub struct OrbitalInfo { pub index: usize, pub energy: f64, pub occupation: f64,
     pub parity: Option<f64> }`
   - `pub fn list(system, result) -> Vec<Vec<OrbitalInfo>>` — **スピンの組ごと**
     （restricted は 1 組、unrestricted は α・β の 2 組。`ScfResult::channels` と同じ並び）。
     `parity` は平面のときだけ。
   - `pub fn spin_pairing(system, result) -> Option<Vec<usize>>` — α の i 番目に対応する β の
     添字（`C_αᵀ S C_β` の行ごとの絶対値最大）。restricted なら `None`。
     **結果が置換になっていることを確かめて返す**（同じ β を 2 つの α が取ったら、その行は
     素直に諦めて `None` を入れられるよう `Vec<Option<usize>>` でもよい。実測では O₂ も NO も
     きれいな置換になった）。
   - `pub fn degenerate_groups(&[OrbitalInfo]) -> Vec<std::ops::Range<usize>>`（しきい値 1e-4 Ha、
     定数にコメントで根拠を書く）。
   - `pub fn signed_column(result, orbital) -> DVector<f64>` — 係数列の写しに**絶対値最大の係数が
     正になる符号**を掛けて返す（同値なら添字の小さいほう）。**`ScfResult` は書き換えない。**
   - `pub fn overlap_population(system, result, orbital, occupation, a, b) -> f64` ＝
     `2 n Σ_{μ∈A, ν∈B} C_μi C_νi S_μν`。`basis.atom_range()` を使う。
     空の軌道は呼ぶ側が `occupation = 1.0` を渡す。
   - `pub fn probe_amplitudes(system, result, orbital) -> Option<Vec<f64>>` — 平面分子のとき、
     各原子核から面の法線方向に **1.0 Bohr** 離れた点での ψ。V4-5 が節を数えるのに使う。
     非平面なら `None`。距離は定数にして、なぜ 1.0 Bohr かをコメントに書く（2p の腹のあたり）。
3. **`pub fn count_lobes(grid: &DensityGrid, level: f64) -> (usize, usize)`**（`density.rs` か
   `marching.rs`）: `+level` より上の連結成分の数と、`−level` より下の連結成分の数。
   6 近傍の flood fill。**箱の外はつながっていない**（周期境界にしない）。
4. `lib.rs` に `pub mod orbital;`。**`bonding::DensityChannel` は触らない**（あれは密度行列を
   返す道で、軌道は別の道）。

## 完了条件

- `cargo test --workspace` が通り、**既存の値が 1 つも動かない**こと。
- 新しいテスト（いちばん強い検算を先に）:
  - **`evaluate_orbital` の検算**: 占有軌道の `Σ_i n_i ψ_i²` を格子の上で足したものが、
    `evaluate` が返す全電子密度と一致すること（水。独立な経路なのでこれが本命）。
  - **符号規約**: 係数列の符号を反転させてから `signed_column` を掛けると元に戻ること。
  - **水**: HOMO の O–H 重なり占有数が 0 に近い（|x| < 0.01 ＝ 孤立電子対）、LUMO（占有 1）が
    負で −0.9 付近、MO1 と MO2 が正。
  - **エチレン**: HOMO と LUMO のパリティが −1、HOMO の C–C が正、LUMO（占有 1）が負。
  - **ベンゼン**: `degenerate_groups` が HOMO を 2 本の組にまとめること、パリティ −1 の
    占有が 3 本・空が 3 本。
  - **O₂**: `list` が 2 組を返し、α の占有が 9 本・β が 7 本。**α の上から 2 本が縮退していて
    重なり占有数が負**（π\*）で、β の同じ 2 本が空。`spin_pairing` が置換になり、
    **添字がそのままではない**こと（4→5、5→6、6→4）。
  - **`evaluate_orbital` の検算（開殻版）**: α と β の占有軌道の ψ² を全部足すと、
    `evaluate` の全電子密度に一致すること。
  - **ローブ**: エチレンの π が 2 個、π\* が 4 個（しきい値を 1 つ決めて）。
- ベンゼンの軌道 1 本の評価が 0.3 秒程度であることを 1 回見ておく（`--release`）。
