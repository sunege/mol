# V4-10 ユーザーの確認（Firefox・講義 PC）

**依存: 全部**

**目的**: Claude の作業ブラウザでは確かめられないところを、ユーザーに見てもらう。
v4 は**見た目そのものが中身**（位相の色、はしご、曲線）なので、ここが実質の受け入れ。

## 前提

  操作はユーザーに Firefox で確認してもらう。パネル・Worker・IndexedDB は Browser ツールで
  確認済みのはず。
- 講義で使う PC: **Windows 11 / i5-1235U / Chrome**。V3-9 の実測ではどれも開発機より速かった
  （ベンゼンを測って 95 秒、Worker 643 MiB、`poolSize` 3）。
- v4 で足したもの: 差電子密度の選択（V4-1）、分子軌道の節と等値面（V4-4）、性格の言葉（V4-5）、
  準位のはしご（V4-6、**開殻は 2 列**）、距離スキャンと相関図（V4-8）。
- **O₂ は開殻**なので、はしごが上向き・下向きの 2 列になる。実測では α の π\* が埋まり β は空、
  同じ π\* が α −0.081 / β −0.001 Ha（交換分裂）。**多重度が画面から読めるのはここだけ**で、
  これは隠す設定ではなく教える中身（plan-v4.md の決定 2・9）。
- **既定の画面は v3 のまま**で、「分子軌道」の節は既定で閉じている。
- 位相は viewer の**青（正）と赤（負）**で、差電子密度と同じ色。
- **V4-4 で画面に出た言葉**（言葉づかいの直しはここで拾う）: 節の見出しは「分子軌道」、閉じて
  いるときの 1 行と、開いたときの読み方の行（「● が電子、○ は空の部屋」、HOMO と LUMO の説明）。
  開殻の列は「上向きのスピン」「下向きのスピン」、しきい値の左右は「ふくらみ全体」
  「強いところ」。**縮退の「同じ高さの軌道が 2 つ」＋ `1 / 2` のボタンは V4-6 で消えて**、
  同じ高さの線が 2 本並ぶ絵になった（何本目かは読み上げにだけ残っている）。
  **軌道を選ぶと「電子の雲を表示する」が自動で入り、節を閉じると軌道の選択が外れて密度に戻る。**

  「C–C を強め、C–H には効いていません。」／「C–C は強めるところと弱めるところがあり、C–H には

## 見てもらうこと

1. **既定の画面が v3 から変わっていないこと**（節が閉じていて、化学を知らない人の道が
   太くなっていないこと）。
2. **差電子密度**: ベンゼンで「結合に寄与する電子」と「原子から動いた電子」を見比べ、
   どちらも意味が読めること。メタンではボタンが 2 つであること。
3. **軌道の絵と位相**: エチレンの HOMO（π）と LUMO（π\*）で、**青と赤の向きが教科書と合うこと**。
   しきい値を動かしたときの見え方。水の HOMO が孤立電子対に見えること。
4. **縮退**: ベンゼンの HOMO の段に線が 2 本あり、**両方見ると形が違う**こと。
   説明の言葉でそれが誤解なく伝わるか。
5. **O₂**: はしごが上向き・下向きの 2 列になり、**上向きの π\* 2 段が埋まって下向きは空**
   であること。「同じ向きのスピンが 1 個ずつ」が言葉と図で伝わるか。
   **上向きと下向きで高さがずれている**（交換分裂）のが、教えたいことの邪魔にならないか。
   π\* の軌道の絵が、結合の間に節のある形に見えること。
6. **性格の言葉**: 「C–C を強めています」「O–H を弱めています」「節 1」が、
   講義で言う言い方と食い違わないか。
7. **準位のはしご**: 内殻が畳まれていること、HOMO–LUMO の開きが見えること、
   段をクリックして軌道が切り替わること。**数字が 1 つも出ていないこと。**
8. **距離スキャン**: H₂ で線が伸びていくのが見えること、分裂の非対称
   （σ\* のほうが大きく上がる）が読めること、**縦線を動かすと 3D の分子が伸び縮みすること**
   （Claude は数値でしか見ていない）。He₂・N₂・O₂ も（O₂ は実線と破線）。
   **講義で使える速さか。** **図の字（σ / π と `●`、横軸の距離）が 300px のパネルで読めるか**
   ＝ 読めないなら `LABEL_GAP` と `LEVELS_HEIGHT` を上げる（V4-9 は触っていない。ここで直す）。
   **相関図の線が「どの原子の準位から来たか」として読めるか**（O₂ は 4 列 24 本で密。
   **多すぎるなら線を減らすか相関図を閉じておくかをここで決める**）。
9. **講義の通し**: H₂（分裂）→ エチレン（π と π\*）→ **O₂（Hund 則と常磁性）**→
   ベンゼン（縮退と非局在）を通しでやってみて、どこで話が止まるか。
10. **講義 PC で 3・5・7・8 が同じに見えること**、ファンと本体の熱。
