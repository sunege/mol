# V4-1 差電子密度を選べるようにする

**依存: なし**

**目的**: 平面分子でも「原子から動いた電子」（差電子密度）を見られるようにする。
今は平面だと π に決め打ちされていて、差電子密度が出せない。

## 前提（これだけ知っていれば着手できる）

- 要求は `DensityRequest = 'total' | 'bonding'`、答えは `DensityChannel = 'total' | 'pi' |
  'deformation'`（`web/src/worker/protocol.ts`）。**`'bonding'` は要求であって答えではない**:
  `bonding::bonding_channel` が、平面で軌道がきれいに分かれるなら π、そうでなければ
  差電子密度を選び、選んだほうが `IsoMesh.channel` で返る。UI は返ってきたもので説明文を変える
  （`App.tsx` の `explainChannel`）。
- **π は平面分子にしかない**（`bonding::molecular_plane` は 4 原子未満と非平面で `None`）。
  差電子密度は**どの分子でも作れる**（分子の密度 − 同じ位置に置いた孤立原子の重ね合わせ ＝
  SCF の出発点に使っている SAD）。
- `Calculation`（`crates/dft-wasm/src/lib.rs`）はチャネルごとにサンプルした格子を
  `total: Option<DensityGrid>` と `bonding: Option<(DensityChannel, DensityGrid)>` に持ち、
  しきい値を動かすだけなら marching cubes だけをやり直す。**1 枚は 300,000 点 × f64 ＝ 2.4 MB。**
- しきい値の範囲は `DensityRequest` をキーにしている（`components/IsoLevelSlider.tsx` の
  `ISO_RANGES`）。
- **CLAUDE.md の「『結合に寄与する電子』はエンジンが選ぶ」は、このチケットで書き換える行。**
  エンジンが選ぶのは `'bonding'` のときだけになる。

## やること

1. **protocol**: `DensityRequest` に `'deformation'` を足す。**答えの `DensityChannel` は変えない**
   （`'deformation'` は既にある）。
2. **`ScfOutcome` に `hasPi: boolean`**: この分子に「面から上下にはみ出す電子」があるか。
   F4 には触れない（平面かどうかは画面を見れば分かる幾何の話で、DFT のパラメータではない）。
   Rust 側は `bonding` に `pub fn has_pi_system(system, result) -> bool` を足し、
   `bonding_channel` と判定を共有する（パリティを見るだけで、格子は作らない）。
3. **`dft-wasm`**: `isosurface` の `channel` に `"deformation"` を足し、キャッシュを 3 枚に
   （`total` / `pi` / `deformation`）。`Vec<(DensityChannel, DensityGrid)>` に置き換えるのが素直。
4. **UI**: ボタンを 3 つにする。
   - `すべての電子`（`'total'`、今のまま）
   - `結合に寄与する電子`（`'bonding'`、**`hasPi` のときだけ出す**）
   - `原子から動いた電子`（`'deformation'`、いつでも出す）
   `ISO_RANGES` に `deformation`（`bonding` と同じ範囲でよい）。`explainChannel` に 1 本足す。
   **選択中のボタンが消えたときは `'total'` に戻す**（分子を編集して平面でなくなったとき）。
5. `hasPi` が来る前（まだ計算していない）は π のボタンを出さない。`showDensity` の扱いは今のまま。
