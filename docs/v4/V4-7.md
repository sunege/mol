# V4-7 距離スキャン（Rust と境界）

**依存: V4-2**

**目的**: 二原子分子の距離を振って解き直し、**各距離の全エネルギーと軌道の準位**を
点が出るたびに返せるようにする。図は V4-8。

## 前提

- **これだけは後処理で出せない。** ただし安い: **H₂ を 0.4〜3.0 Å の 27 点で 0.41 秒**
  （STO-3G/LDA、restricted、Medium グリッド、各点 6 反復で収束、`System::build` 込み。
  ネイティブ release、dev-notes「v4-0 の実測」）。

  | R/Å | ε(σ)/Ha | ε(σ\*)/Ha | E/Ha |
  | --- | --- | --- | --- |
  | 0.40 | −0.48557 | +0.85799 | −0.89753 |
  | 0.70 | −0.36065 | +0.43972 | −1.11999 |
  | 1.40 | −0.21210 | +0.05578 | −0.98875 |
  | 3.00 | −0.10844 | −0.08923 | −0.79616 |

  遠いと縮退、近づくと分裂し、**σ\* の上がり方が σ の下がり方より大きい**という教科書の
  非対称まで出る。
- **スピン状態は 1 回だけ選んで固定する。** 各点で `driver::solve` に選ばせると、伸ばした H₂ では
  三重項が勝って図が飛ぶ（R = 3.0 Å の restricted は −0.796 Ha で、H 原子 2 個より高い）。
  構造最適化が状態を 1 回だけ選んで全歩で固定しているのと同じ扱い（`dft-wasm` の `optimize`）。
- **線は対称種ごとに n 番目どうしをつなぐ**（準位の並び順は交差で入れ替わる。同じ対称種は
  交差しない）。**二原子分子の σ と π は縮退で分ける**: π は 2 重に縮退し、σ は縮退しない
  （STO-3G の H–Ar に δ は無い）。縮退のまとめ方は V4-2 の `orbital::degenerate_groups`。
- **1 枚の鏡映面で σ と π を分けてはいけない**（実測、dev-notes「v4-0 の実測」）。
  O₂ の α4 と α5 は**同じエネルギー（−0.35068）で同じ重なり占有数（+0.1321）＝ 縮退した π の組**
  なのに、軸を含む平面を構成してパリティを測ると **+1.000 と −1.000** に割れる（面の向きが組の
  片方と揃うとこうなる）。`bonding::PARITY_THRESHOLD = 0.8` はこれを「きれいに分かれている」と
  受け取ってしまう。**平面分子の π 判定（鏡映）はそのままでよい**（そちらは面が分子で決まっていて
  任意性が無い）。幾何の違う 2 点の軌道を重なりで対応づけるには中心の違う基底どうしの
  重なり積分が要るので、そちらも採らない。
- **開殻も回せる**（O₂）。`ScfResult::channels` が 2 組になるだけで、点ごとに**両方**返す。
  図では線が 2 倍になる（V4-8 の仕事）。
- 規約: **`dft-core` に wasm 依存も時計も入れない**（予算・進捗はクロージャで受ける）。
  **`dft-wasm` は単位変換とシリアライズだけで物理を書かない。**
- **段は「形を探す」（STO-3G）固定**（plan-v4.md の決定 7）。最小基底の 2×2 が教科書の図そのもの。
- 実測の値段: O₂ は 1 点 0.08 秒（三重項、7 反復）、NO は 0.81 秒（39 反復）、N₂ は 0.07 秒。
- **V4-2 で入ったもの**（`crates/dft-core/src/orbital.rs`）:
  - `orbital::degenerate_groups(&[OrbitalInfo]) -> Vec<Range<usize>>` は `OrbitalInfo` の
    スライスを取るので、**各点で `orbital::list(&system, &result)` を通してから段にまとめる**
    （組ごとに 1 本の `Vec`。`ScanLevel::spin` はその添字）。`count` は `Range::len()`、
    `energy` と `occupation` は組の先頭の軌道のもの。しきい値は
    `orbital::DEGENERACY_TOLERANCE`（1e-4 Ha、`pub`）。
  - **二原子分子では `list` の `parity` が必ず `None`**（`molecular_plane` は 4 原子未満で
    `None` を返す）。「1 枚の鏡映面で σ と π を分けてはいけない」は、構造的にその道が
    通じないという形で守られている。
  - **伸ばした H₂ でも σ と σ\* は畳まれない**: 3.0 Å の差は 0.019 Ha ＝ しきい値の 190 倍
    （上の表から）。完了条件の「H₂ の段は全部 `count == 1`」はそのまま通る。

## やること

1. **`crates/dft-core/src/scan.rs`（新規）**:
   - `pub struct ScanLevel { pub energy: f64, pub occupation: f64, pub count: usize,
     pub spin: usize }`（`count` が 2 なら π、1 なら σ。`spin` は `ScfResult::channels` の
     添字で、閉殻なら 0 だけ）。
   - `pub struct ScanPoint { pub distance: f64, pub energy: f64, pub converged: bool,
     pub levels: Vec<ScanLevel> }`。単位は Bohr/Hartree。
   - `pub fn distance_scan(z: [u8; 2], from: f64, to: f64, points: usize, kind: BasisKind,
     on_point: &mut dyn FnMut(ScanPoint) -> bool) -> ()`。
     - **いちばん短い距離で 1 回だけ `driver::solve` を呼んで状態を決め**、以降はその状態で
       `scf::run_restricted` / `run_unrestricted` を回す。
     - 各点で `degenerate_groups` で段にまとめ、`levels` に載せる（**縮退の本数が対称種**）。
     - `on_point` が `false` を返したら止める（**時計は中に入れない**）。
   - `lib.rs` に `pub mod scan;`。
2. **原子の準位**（V4-8 の相関図の両側）: `scf::guess` に
   `pub fn atomic_levels(z: u8, kind: BasisKind) -> Vec<f64>` を足す。中身は今の
   `atomic_density` と同じ原子 SCF で、密度の代わりにエネルギーを返すだけ（数 ms）。
   **表を記憶から書かない**（計算して返す）。
3. **`dft-wasm`**: `pub fn scan(z: &[u8], from_angstrom, to_angstrom, points, on_point)` と
   `pub fn atom_levels(z: &[u8])`。距離は Å ↔ Bohr をここで変換。
   `on_point` が例外を投げたら止める（候補の予算と同じ作法）。
4. **protocol**:
   - `{ id; type: 'scan'; z: Uint8Array; from: number; to: number; points: number;
     budgetMs?: number | null }` → `{ id; type: 'scanPoint'; point: ScanPoint }` を points 回、
     最後に `{ id; type: 'scanDone' }`。`isTerminal()` は `scanPoint` を**中間**として扱う
     （`step` と同じ）。
   - `{ id; type: 'atomLevels'; z: Uint8Array }` → `{ id; type: 'atomLevels'; levels: number[][] }`。
   - `points` の上限は **60**（doc コメントに理由: H₂ の 27 点が 0.4 秒、N₂ ならその数倍）。
   - **止め方**: 予算切れは `budgetMs` で、ユーザーの中止は `terminate()`。
     **止めると保持中の `Calculation` も消える**（`hasDensityRef` が落ちる ＝ 等値面は
     SCF からやり直し）ことをコメントに書く。
5. `workerClient.ts` に `scan(z, from, to, points, onPoint, budgetMs?)` と `atomLevels(z)`。

## 完了条件

- `cargo test --workspace` / `npm test`。
- Rust のテスト（**数字は上の表から**、ゆるい許容で）:
  - H₂ の 0.4 Å で σ と σ\* の差が 1.3 Ha 以上、3.0 Å で 0.03 Ha 以内。
  - R を増やすと **σ は単調に上がり、σ\* は単調に下がる**。
  - 全点が収束し、状態が全点で同じであること（途中で三重項に化けない）。
  - H₂ の段は**全部 `count == 1`**（σ しかない）。
  - **N₂** の平衡付近で **`count == 2` の段が占有側に 1 つ（π）と空側に 1 つ（π\*）**あること。
  - **O₂** の平衡付近で**スピンの組が 2 つ**返り、占有が上向き 9 本・下向き 7 本で、
    **上向きの上から 2 本（`count == 2`）が占有、下向きの同じ段が空**であること。
- `engine.test.ts` で実物の `.wasm` を呼び、H₂ の 27 点が返ること。
- **`npm run build:wasm` して `web/src/wasm/` をコミット。**
