# V4-5 軌道の性格を言葉にする（結合性・反結合性・節）

**依存: V4-4**

**目的**: 選んだ軌道について、「どの結合を強めているか／弱めているか」「ローブがいくつか」
「節面が何枚か」を、絵の解釈ではなく計算値として出す。

## 前提

- **判定の中身は V4-2 で入っている**: `orbital::overlap_population(system, result, orbital,
  occupation, a, b)` ＝ Mulliken の重なり占有数 `2 n Σ_{μ∈A,ν∈B} C_μi C_νi S_μν`。
  **正なら結合性、負なら反結合性、0 なら非結合。** 空の軌道は `occupation = 1.0` で呼ぶ。
  実測（STO-3G/LDA、dev-notes「v4-0 の実測」）:
  - **水**: MO1 +0.298、MO2 +0.335（O–H 結合性）、**HOMO −0.0000（孤立電子対）**、
    **LUMO −0.934（反結合）**。
  - **エチレン**: HOMO の C–C +0.384、LUMO の C–C −0.312（π と π\*）。
- **ローブの数は等値面と一緒に返っている**（`IsoMesh.lobes`）。**いまのしきい値での数**なので、
  スライダーを動かすと変わる。そう書く。
- **節の数は一般の軌道では定義できない。** 教科書が数えるのは平面共役系の π だけなので、
  **数えるのもそこだけ**にする（`parity === -1` かつ平面）。
- 節を数える材料は `orbital::probe_amplitudes`（各原子核から面の法線に 1.0 Bohr 離れた点での ψ）。
  V4-2 で実装済みで、**`molecule.atoms` の順に全原子ぶん**返る（非平面なら `None`）。符号は
  `orbital::signed_column` の規約（絶対値最大の係数が正）。**水素にも値が乗る**
  （エチレンの π は C が +0.257、H が +0.028 ＝ 最大の 11% で、下の 5% の足切りでは落ちない）。
  幸い C–H に沿って符号は変わらないので数は合うが、足切りを頼りにしないこと。
  **結合のつながり方は UI 側にある**: `web/src/scene/bonds.ts` の `findBonds` が共有半径から
  結合の組を作っている（表示のための推定で、エンジンは見ていない）。
- **数え方**: 結合に沿って探針点の符号が変わる回数を数え、**π 系が環なら 2 で割る**、
  鎖ならそのまま。振幅が小さい原子（最大値の 5% 未満）は符号なしとして飛ばす。
  - エチレン: π は `+ +` で 0 回 → **節 0**、π\* は `+ −` で 1 回・鎖 → **節 1**。
  - ベンゼンの HOMO は縮退の 2 本で、片方は `+ + − − − +`（2 回）、もう片方は
    `0 + + 0 − −`（0 を飛ばして 2 回）。環なので 2 ÷ 2 ＝ **どちらも節 1**。
    **これが実装の合否を決めるテスト。**
- F4: 軌道エネルギーの数値は出さない。ここで出る数値は**重なり占有数の符号と大小の言葉だけ**
  （数値そのものも出さない。「強めている / 弱めている / どちらでもない」）。

## やること

1. **protocol に軽い要求を 1 つ**: `{ id; type: 'orbitalCharacter'; index: number;
   spin?: SpinChannel }` →
   `{ id; type: 'orbitalCharacter'; populations: Float64Array; amplitudes: Float64Array | null }`。
   `populations` は原子数 × 原子数（ベンゼンで 144 個。格子は作らないので数 ms）、
   `amplitudes` は原子ごと（非平面なら `null`）。**どの結合を見るかは UI が決める**ので、
   組ではなく行列で渡す。
2. **`dft-wasm`**: `Calculation::orbital_character(index, spin)`。占有が 0 の軌道は
   `occupation = 1.0` で計算する（そうしないと全部 0 になる）。
   **開殻では占有 1 の軌道も 1.0 で計算する**（上向きと下向きを同じ物差しで比べられるように。
   数値は画面に出さず符号と大小だけを言うので、これで筋が通る）。
3. **`web/src/components/orbital.ts` に足す**（V4-4 で作ったモジュール）:
   - `describeBonds(populations, bonds, symbols)` — 「C–C を強め、C–H には効いていません」。
     しきい値（どこからを「効いていない」とするか）は定数にして根拠をコメントに書く
     （水の孤立電子対はちょうど −0.0000、結合性の軌道は +0.3 前後。間のどこで切るかは
     手持ちの分子で見て決め、V4-9 の実測で詰め直してよい）。
   - `countNodes(amplitudes, bonds)` — 上の数え方。環の判定は「結合の数 ≥ 原子の数」。
     π 以外や非平面では `null`。
   - `describeLobes(lobes)` — 「いまのしきい値では、かたまりが 4 つに分かれています」。
4. **UI**: 選んだ軌道の下に 2〜3 行。軌道を変えたときだけ取りに行く（しきい値では取りに行かない）。

## 完了条件

- `npm test` / `npm run lint --workspace web` / `cargo test --workspace`。
- **`countNodes` のテスト**（`orbital.test.ts`）: 上の 3 つの例（エチレンの π と π\*、
  **ベンゼンの縮退した HOMO 2 本がどちらも 1**）を、振幅の配列と結合の組を手で与えて確かめる。
  **数字は「軌道の形」から作る**（係数を記憶から書かない。`0 + + 0 − −` のような符号の列でよい）。
- `describeBonds` に F4 の禁止語が無いこと。
- Claude のブラウザ: 水の HOMO で「どの結合も強めていません」、LUMO で「O–H を弱めています」、
  エチレンの HOMO で「C–C を強めています · 節 0」が出ること。
  **O₂ の上向きの上から 2 段で「O–O を弱めています」**（π\*、重なり占有数 −0.1796）。
