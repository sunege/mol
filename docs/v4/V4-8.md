# V4-8 距離スキャンの図と二原子分子の相関図

**依存: V4-6, V4-7**

**目的**: 「原子を近づけると準位が分裂して結合性と反結合性になる」を画面で見せる。
二原子分子のときだけ出る。

## 前提

- **V4-7 で入ったもの**（実測は dev-notes「V4-7 の実装メモ」）:
  - `client.scan(z, from, to, points, onPoint, budgetMs?)` が点ごとに
    `{ distance, energy, converged, levels: [{ energy, occupation, count, spin }] }` を流し、
    **`scanDone` で終わる**（`Promise<void>`。`scanDone` は何も運ばないので、**予算で切れたかは
    受け取った点の数を数える**）。距離は Å、エネルギーは Ha。
  - **`count` が対称種**（2 なら π、1 なら σ。パリティではない ＝ 1 枚の鏡映面では割れるため。
    `ScanLevel` に `parity` も `partner` も `first` も無い）、`spin` はスピンの組の添字
    （閉殻は 0 だけ、開殻は 0 と 1）。**`occupation` は `OrbitalLevel` と同じ「組の中の 1 本
    あたり」**なので、V4-6 の `occupationMark` にそのまま渡せる。
  - `client.atomLevels(z)` が元素ごとの原子軌道の準位（`number[][]`、Ha、昇順）を返す。
    **原子は球対称に解いているのでスピンで分かれず、相関図の両端は 1 列**。計算が載っていなくても
    答える（`orbitals()` と違う）。
  - **点の数の上限は 60**（`MAX_SCAN_POINTS`。Worker が拒否する）。
  - **スキャンは保持中の計算を触らない**ので、画面の等値面はスキャン中も生き残る。
    消えるのは `cancelCalculation()`（＝ `cancelAll()`、Worker ごと捨てる）で止めたときだけで、
    そのときは**等値面が SCF からやり直し**になる。
- 実測（Node、3 回の最小値。ネイティブの約 3 倍）: **H₂ の 27 点が 1.20 秒**（1 点 44 ms）、
  60 点で 2.73 秒。**N₂ 2.55 秒**（1 点 95 ms、8 段）、**O₂ 4.64 秒**（1 点 172 ms、16 段）、
  HF 5.59 秒、He₂ 1.17 秒。**線形メモリは 6 MiB で止まる**（格子を作らない）。
  ブラウザはこれよりさらに遅いので、**進捗は必ず出すこと**。
- **HF は 1.89 Å から先で収束しない**（27 点中 5 点。一重項固定で極性結合を切ると RKS が解を
  見失う）。**エネルギーが 0.7 Ha 跳ねて暴れる**ので、**縦軸のスケールは `converged: false` の点を
  外して決める**（外さないと曲線が潰れる）。既定のプリセットは **1.8 Å より手前で止める**。
  点そのものは契約どおり届くので、曲線の穴として描くか飛ばすかは図の側で決める。
- **数値は出さない**（plan-v4.md の決定 3）。縦軸は高さだけ、横軸は距離（Å は出してよい ＝
  画面に出ている長さと同じ単位で、DFT のパラメータではない）。
- **グラフは自前の SVG**（cross-origin isolated なので CDN のチャートライブラリは読めない）。
- **線のつなぎ方は V4-7 が決めている**: 対称種（縮退の本数）ごとに n 番目どうし。
  UI は届いた順に並べるだけで、並べ替えない。
- **開殻では線が 2 倍**（O₂）。**実線が上向き、破線が下向き**にする。
  既定のプリセットは閉殻（H₂・He₂・N₂・HF）にし、**O₂ は静的なはしご（V4-6）が主役**だが、
  スキャンも回せるようにする。
- はしごの部品は V4-6 の `components/ladder.ts` / `OrbitalLadder.tsx`。相関図の中央はこれ。
- **V4-6 で入ったもの**（実測は dev-notes「V4-6 の実装メモ」）:
  - **`buildLadder(levels)` が絵を丸ごと組み立てる**（列・段・線の x と y・`partner` の線・
    内殻の 1 行・文字列まで）。`OrbitalLadder` は `levels` / `picked` / `onPick` の 3 つだけで
    描けるので、**相関図の中央にそのまま置ける**。切り出して使うなら `foldCore(levels)`（内殻）と
    `layout(shown, height)`（y 座標）が別々に呼べる。
  - **両端の原子の列も同じ `layout` で置くとよい**: 高さは energy に比例させ、近すぎる段だけ
    `MIN_STEP`（13 単位）まで押し広げる。**押し広げは局所**なので大きな開きは潰れない。
  - **viewBox の幅は 260 単位・文字は 9.5 単位**（300px のパネルで約 10px）。スキャンの図も
    同じ単位にすると、はしごと大きさが揃う。
  - **占有の記号は `occupationMark`**（`●●` / `●` / `○`）、**読み上げは `ladderRungLabel`**。
    V4-4 の `1 / 2` ボタン（`memberLabel` / `MEMBER_GROUP_LABEL`）は**消えた**。
  - **`partner` は「返ってきた配列」の添字**で、畳んだあとの配列ではずれる。段は
    `spin:first` の鍵で引くこと（O₂ では実測で線が 6 本、2 本が交差する）。
  - **クリックとキーボードの作法**: 列ごとに 1 つのタブ止まり（roving tabindex）、
    上下左右で選択とフォーカスが一緒に動く、Enter / Space で選ぶ、矢印は `preventDefault`。
- **He₂ は測った（V4-7）。E(R) は教材にならない**: 2.46 Å に極小はあるが **4.0 Å との差が
  8.9e-5 Ha ＝ 0.24 kJ/mol** で、3 Å より遠くは 1e-5 Ha のグリッドノイズと同じ桁で平ら
  （記録の「同じ谷」1 kJ/mol より 4 倍小さい）。**短距離の立ち上がりは本物**（1.5 Å で 0.015 Ha 高い）。
  **He₂ で見せるのは段の絵**（σ と σ\* が両方埋まる）**で、E(R) の谷ではない。**

## やること

1. **`web/src/components/scan.ts`（新規、純粋な計算）**: 届いた点から
   - 曲線 2 本分の座標（全エネルギー、準位ごと）
   - 準位を対称種でまとめた並び
   - 「いちばん低い点」の距離
   テストは `scan.test.ts`（点の列を手で与える）。
2. **`web/src/components/DistanceScan.tsx`（新規）**: SVG 2 段。
   - 上: 準位（点が届くたびに線が伸びる）。占有は V4-6 と同じ記号。
   - 下: 全エネルギー。
   - 縦線 1 本でいまの距離を示し、**動かすとその距離の形が 3D に置かれる**（`setAtoms`）。
     その距離で軌道を見たければ、そこで 1 回だけ SCF を回す（`client.scf`）。
   - **軸に数字を入れるのは横軸（距離）だけ。**
3. **二原子分子の相関図**: 左右に `atomLevels` の準位（**原子は球対称に平均して解いているので
   スピンで分かれない。1 列**）、中央に分子の準位（**閉殻は 1 列、開殻は V4-6 と同じ 2 列**）、
   **AO 組成で線を結ぶ**（組成は V4-5 の `populations` と同じ道で取れる原子ごとの
   Mulliken 全占有数。無ければこのチケットで `orbitalCharacter` に 1 つ足す）。
   **3 原子以上では相関図を出さない**（線の束になって読めない。plan-v4.md）。
4. **App**: 「分子軌道」の節の中に、**原子がちょうど 2 個のときだけ**「近づけてみる」を出す。
   プリセット（H₂・He₂・N₂・HF・**O₂**）から選べるようにし、いまの 2 原子でも回せる。
   **計算中は出さない / 押せない**（前面の Worker を 1 本しか使わないため）。
5. スキャン中の進捗は「N / 27 点」。途中で止める道を用意する（`cancelCalculation()` と同じ扱い ＝
   形は残らない。**止めると等値面も解き直しになる**ことを 1 行で言う）。

## 完了条件

- `npm test` と `npm run lint --workspace web`。
- `scan.test.ts` が、点の列から曲線の座標と対称種の並びを作れることを固定している。
- SVG のテキストに**エネルギーの数値が出てこない**ことをテストで固定する。
- Claude のブラウザ（WebGL 無し）で**パネルの動作**: H₂ のスキャンが 27 点流れてきて
  2 本の線が伸びること、縦線を動かすと 3D の原子の距離が変わること（`atoms` の値で見る）、
  He₂ で σ と σ\* の両方が埋まっていること、**O₂ で実線と破線が出て、平衡付近で上向きの π\* だけが
  埋まっていること**。**実際にどう見えるかはユーザーに**（V4-10）。
- ~~He₂ の E(R) を測る~~ **V4-7 で測った**（dev-notes「V4-7 の実装メモ」）。
  講義で言えるのは「E(R) に谷が無い」ではなく**「谷が 0.24 kJ/mol しかない」**なので、
  **図の主役は段のほうにすること。**
