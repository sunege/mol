# V4-8 距離スキャンの図と二原子分子の相関図

**依存: V4-6, V4-7**

**目的**: 「原子を近づけると準位が分裂して結合性と反結合性になる」を画面で見せる。
二原子分子のときだけ出る。

## 前提

- V4-7 で入ったもの: `client.scan(z, from, to, points, onPoint, budgetMs?)` が点ごとに
  `{ distance, energy, converged, levels: [{ energy, occupation, count, spin }] }` を流し、
  最後に終わる。**`count` が対称種**（2 なら π、1 なら σ。パリティではない ＝ 1 枚の鏡映面では
  割れるため）、`spin` はスピンの組の添字（閉殻は 0 だけ、開殻は 0 と 1）。
  `client.atomLevels(z)` が元素ごとの原子軌道の準位を返す。
  **点の数の上限は 60。止めると保持中の計算も消える**（等値面は解き直し）。
- 実測: **H₂ の 27 点が 0.41 秒**（ネイティブ）。ブラウザでは数倍。
- **数値は出さない**（plan-v4.md の決定 3）。縦軸は高さだけ、横軸は距離（Å は出してよい ＝
  画面に出ている長さと同じ単位で、DFT のパラメータではない）。
- **グラフは自前の SVG**（cross-origin isolated なので CDN のチャートライブラリは読めない）。
- **線のつなぎ方は V4-7 が決めている**: 対称種（縮退の本数）ごとに n 番目どうし。
  UI は届いた順に並べるだけで、並べ替えない。
- **開殻では線が 2 倍**（O₂）。**実線が上向き、破線が下向き**にする。
  既定のプリセットは閉殻（H₂・He₂・N₂・HF）にし、**O₂ は静的なはしご（V4-6）が主役**だが、
  スキャンも回せるようにする。
- はしごの部品は V4-6 の `components/ladder.ts` / `OrbitalLadder.tsx`。相関図の中央はこれ。
- **He₂ が良い題材かどうかは測って決める**（σ と σ\* が両方埋まる図は出るが、
  LDA が浅い極小を作るかどうかは測っていない。**単調に上がると書く前に確かめること**）。

## やること

1. **`web/src/components/scan.ts`（新規、純粋な計算）**: 届いた点から
   - 曲線 2 本分の座標（全エネルギー、準位ごと）
   - 準位を対称種でまとめた並び
   - 「いちばん低い点」の距離
   テストは `scan.test.ts`（点の列を手で与える）。
2. **`web/src/components/DistanceScan.tsx`（新規）**: SVG 2 段。
   - 上: 準位（点が届くたびに線が伸びる）。占有は V4-6 と同じ記号。
   - 下: 全エネルギー。
   - 縦線 1 本でいまの距離を示し、**動かすとその距離の形が 3D に置かれる**（`setAtoms`）。
     その距離で軌道を見たければ、そこで 1 回だけ SCF を回す（`client.scf`）。
   - **軸に数字を入れるのは横軸（距離）だけ。**
3. **二原子分子の相関図**: 左右に `atomLevels` の準位（**原子は球対称に平均して解いているので
   スピンで分かれない。1 列**）、中央に分子の準位（**閉殻は 1 列、開殻は V4-6 と同じ 2 列**）、
   **AO 組成で線を結ぶ**（組成は V4-5 の `populations` と同じ道で取れる原子ごとの
   Mulliken 全占有数。無ければこのチケットで `orbitalCharacter` に 1 つ足す）。
   **3 原子以上では相関図を出さない**（線の束になって読めない。plan-v4.md）。
4. **App**: 「分子軌道」の節の中に、**原子がちょうど 2 個のときだけ**「近づけてみる」を出す。
   プリセット（H₂・He₂・N₂・HF・**O₂**）から選べるようにし、いまの 2 原子でも回せる。
   **計算中は出さない / 押せない**（前面の Worker を 1 本しか使わないため）。
5. スキャン中の進捗は「N / 27 点」。途中で止める道を用意する（`cancelCalculation()` と同じ扱い ＝
   形は残らない。**止めると等値面も解き直しになる**ことを 1 行で言う）。

## 完了条件

- `npm test` と `npm run lint --workspace web`。
- `scan.test.ts` が、点の列から曲線の座標と対称種の並びを作れることを固定している。
- SVG のテキストに**エネルギーの数値が出てこない**ことをテストで固定する。
- Claude のブラウザ（WebGL 無し）で**パネルの動作**: H₂ のスキャンが 27 点流れてきて
  2 本の線が伸びること、縦線を動かすと 3D の原子の距離が変わること（`atoms` の値で見る）、
  He₂ で σ と σ\* の両方が埋まっていること、**O₂ で実線と破線が出て、平衡付近で上向きの π\* だけが
  埋まっていること**。**実際にどう見えるかはユーザーに**（V4-10）。
- He₂ の E(R) が実際にどうなるかを 1 回測り、**dev-notes に 1 行**書く
  （講義で「だから He₂ は無い」と言えるかどうかが変わる）。
