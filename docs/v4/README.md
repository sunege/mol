## v4 で決まっていること（全チケットに効く）

1. **モードは作らない。** パネルに既定で閉じた「分子軌道」の節を 1 つ足すだけ。
2. **F4 は「既定の画面に出さない」に読み替える。** 節の中でも**基底・汎関数・電荷・試行回数は
   出さない**。出してよいのは軌道の絵・占有・相対的な準位・結合性/反結合性。
   **多重度だけは例外**（O₂ を扱うので占有から読める。隠す設定ではなく教える中身）。
3. **軌道エネルギーの数値は出さない**（LDA の絶対値は桁が違う。水の HOMO は −1.6 eV、実験は 12.6 eV）。
   準位図は**高さだけ**。
4. **軌道の節は「形を探す」（STO-3G）の結果のときだけ**中身を出す。
5. **縮退は組として扱う**（しきい値 1e-4 Ha）。1 本だけ見せない。
6. **位相の全体符号は規約で固定する**（絶対値最大の係数を正にする）。
7. **開殻も扱う（O₂）。上向きと下向きは 2 列に分けて畳まない**（同じ π\* が α −0.081、
   β −0.001 Ha と交換分裂が大きい）。**α と β の対応づけは添字ではなく重なり `⟨α_i|S|β_j⟩`**
   （O₂ では並びが 4→5、5→6、6→4 と入れ替わる）。
   **二原子分子の σ/π は縮退で分ける**（1 枚の鏡映面では割れる。O₂ の縮退した π の組が
   +1.000 と −1.000 に出た）。開殻が効くのは **V4-2・V4-3・V4-4・V4-6**。
8. **グラフは自前の SVG**（cross-origin isolated なので CDN のチャートライブラリは読めない）。

理由は [docs/plan-v4.md](../plan-v4.md)、数字は dev-notes「v4-0 の実測」。

## 全チケットに共通する前提

- **単位**: エンジンは Bohr/Hartree、UI は Å。変換は `dft-wasm` の境界だけ。
- **`web/src/wasm/` は生成物だがコミットする**（`npm run build:wasm`）。Rust を触ったら忘れない。
- テストは `cargo test --workspace` と `npm test`（web）。
- **Claude の作業ブラウザは WebGL が使えない。** パネル・Worker・IndexedDB は Browser ツールで
  確かめられるが、**3D の見た目とクリック操作はユーザーに Firefox で見てもらう**（V4-10）。
