# V7-8 ユーザーの確認（Firefox・講義 PC）

**依存: 全部**

**目的**: Claude の作業ブラウザでは見られない 3D の見た目（+/− の印・差密度）と、講義 PC での
動きをユーザーに確かめてもらい、指摘を直す。このセッションで Claude がやるのは、確認の手順を
渡すこと・指摘の手直し・最後の記録。

## 確認してもらうこと（Firefox、開発機）

1. **ボタン（V7-4）**: 計算タブで原子を選ぶと「イオン」の 3 つが押せる。選んでいないと全部無効。
   H ひとつだけのとき「+ にする」が無効。
2. **印（V7-5）**: + にした原子に「+」、− に「−」。回しても原子に付いてくる。「安定な形にする」の
   アニメーション中も付いてくる。中性に戻す・原子を消すと消える。差密度の青・赤と紛れない。
3. **H₂O + H⁺ → H₃O⁺**: H₂O のプリセットに H を 1 つ置いて + にし、「安定な形にする」。
   三角錐になる。「原子から動いた電子」で、+ にした H のまわりに電子が流れ込んで（青く）見える。
   同じ形を「O を +、H は中性」で置き直すと、形とエネルギーは同じで差密度だけが違う。
4. **NH₃ + H⁺ → NH₄⁺**: 正四面体になり、どの H がプロトンだったか見分けがつかない。
5. **陰イオン**: OH（O を −）で注意書きが計算タブと観察タブに出る。
6. **記録（V7-6）**: H₃O⁺ を記録するとツリーに「H₃O⁺」の行ができ、中性の H₃O とは別の行。
   開くと + の印が戻る。書き出し → 読み込みで戻る。v6 の書き出しファイルも読める。
7. **二原子（V7-7）**: H₂ の 1 つを + にして分子軌道と「近づけてみる」を開く。スキャンが
   中性より手前で終わり、注意の 1 文がある。相関図の原子の列が「H⁺」と「H」。
8. **CH₄ の H を 1 つ + にする（V7-0 で見つけたこと）**: 正四面体の CH₄⁺ は二重項が収束せず、
   高い多重度に落ちて最適化で形が崩れる（dev-notes「v7-0 の実測」の 6）。画面でどう見えるか
   （発散のアニメーションか、崩れた形か）を見て、講義で困るなら別のチケットにする。
9. **出ていないこと**: 多重度・基底・汎関数・原子ごとの計算上の電荷の数字がどこにも無い。

## 講義 PC（Windows 11 / i5-1235U / Chrome）

  （H₂O と同じくらいのはず）。

## V7-5 で入ったもの

- **印の置き方**: 原子の球（元素の半径 × 0.32）の**輪郭の上、カメラから見て右上 45°**に印の中心を置く
  （`scene/badges.ts` の `badgeAnchor`。半分が球に重なり半分がはみ出す、アプリのアイコンのバッジの形）。
  向きは**カメラの右・上**なので、**毎フレーム置き直す**（viewer の `#placeChargeBadges()`、tick から）。
  見た目は `.charge-badge`（`App.css`）: 直径 1.1rem の丸、地 `#151a21`・枠 `#2d3644`・文字 `#d6dde8` の太字。
  文字は `badgeText` の `+` / `−` だけ。
- **Claude の作業ブラウザでは viewer そのものが作られない**（WebGL が無いと `MoleculeViewer` の
  コンストラクタで落ち、`.viewer-labels` の層も無い）ので、**印の DOM は一度も見ていない**。1〜2 の前に
  開発者ツールで `document.querySelectorAll('.charge-badge').length` を見てもらうとよい（H₂O の H を + で 1、
  中性に戻すと 0、全消去で 0）。
- **確認してほしい点**（上の 2 に足す）:
  - **回したとき**: 印がいつも原子の右上にあり、原子から離れて見えないか。ズームで近づく・遠ざかると、
    印の大きさは画面上で一定、原子の球だけが大きさを変える（遠いと印が原子より大きく見えうる）。
  - **原子が重なったとき**: 印は HTML の層なので**奥の原子の印も手前の原子の上に出る**（隠れない）。
    H₃O⁺ を横から見て紛らわしくないか。紛らわしければ、奥の印を薄くするなどを別チケットに。
  - **アニメーション中**: 「安定な形にする」の毎フレームで付いてくるか（`setPositions` が電荷を保つように直した）。
  - **計測の値・結合の長さのラベルと重ならないか**（同じ層。「結合の長さ」を付けた H₃O⁺ で）。
  - **大きさ**: 講義 PC の小さい画面で読めるか、原子を隠しすぎないか。

## V7-6 で入ったもの

- **見出し**: ツリーの分子の行は `headingOf(record)` ＝ Hill 式 + `outcome.charge` の上付き（H₃O⁺・HO⁻・
  O₂²⁻）で、**電荷が違えば別の分子の行**（H₃O⁺ と H₃O は並ぶ 2 行、束ね直しは無い）。記録の名前の既定も
  「H₃O⁺ · 10:56」。画面の分子の行（`current`）も電荷込みで、H を + にすると H₂O の行から H₂O⁺ の行に移る
  （その分子の記録がまだ無ければ、どの行にも印が付かない）。「…」の「書き出す」「消す」も電荷込みの見出しで束ねる。
- **開いたとき**: 記録を開くと `atoms` に `charge` が戻る（Browser ペインで H₃O⁺ の 4 番目の H が
  `charge: 1` を確認済み）。**3D の + の印が戻るかは 6 で見てほしい**（viewer は `setMolecule` で作り直すので
  手直しは無い）。**電荷のある記録の等値面**（「原子から動いた電子」）がイオン基準で出るかも 6 で。
- **ファイル**: 書き出しは `version: 2`、各記録に `charges`。v1 のファイル（`docs/C₃H₆-記録-20260920-1859.json`）
  は中性として読む（`npm test` と Browser ペインで確認済み）。6 の「書き出し → 読み込みで戻る」は、
  **一度「…」から消してから読み込む**（同じ `id` は重ねない ＝ 消さないと何も起きないように見える）。
  **v6 までの記録を含めて「書き出す」→ 読み込めること**も見てほしい（ブラウザの古い記録は `charges` が
  無く、書くときに全部 0 で補う。Browser ペインの 25 件では通った）。
- **v7 より前の穴の記録**: V7-4 の確認で入った H₂O⁺ と OH⁻ の記録（`charges` 無し、`outcome.charge` ±1）は、
  見出しは「H₂O⁺」「HO⁻」になったが、**開くと原子は中性で戻る**（どの原子に付けたかが残っていない）。
  ユーザーの Firefox にも同じ時期の記録があれば同じ見え方で、消してよい。

## V7-7 で入ったもの

- **範囲**: 合計の電荷が 0 でない二原子は、プリセット（H₂ の 0.4〜3.0 Å など）を使わず**画面の距離の
  0.7〜1.4 倍**（`scanPairFor(z, distance, charges)`、`CHARGED_REACH`）。H⁺ + F⁻ のように合計 0 なら
  中性と同じ（HF のプリセット）。**図の下に 1 文**「電気を帯びた分子は、原子を離しすぎると計算が当てに
  ならなくなるので、右端をここまでにしています。」（`SCAN_CHARGED_NOTE`）。
- **範囲は画面の距離が中心**なので、H₂ の形のまま（0.74 Å）H を + にすると 0.52〜1.04 Å で、H₂⁺ の谷は
  右の外になる。そのときは新しい注意「この図の中では右端がいちばん低く、落ち着く距離はもっと遠いところに
  あります。」が出る（V7-7 で足した。それまでは「谷と呼べるものがありません」と誤って出ていた）。
  **先に「安定な形にする」を押してからスキャンすると谷が真ん中に来る**。講義での手順としてどちらが
  自然かを見てほしい。
- **相関図**: 両端は置いたとおりのイオン（見出し「H⁺」「H」、He + H⁺ なら「He」「H⁺」）。H⁺ の線を押すと
  「H⁺ の 1s。結合する前の、電子の入っていない、イオンひとつの部屋です。」、O⁻ なら「O⁻ の 2p。…、
  イオンひとつの部屋です。」。線の読み上げ名（`aria-label`）も「H⁺ のイオンの部屋、1s」。
- **マーカー**: 動かしても + は付いたまま（`alongTheAxis` が電荷を保つ）で、止まって 400 ms の一点計算も
  電荷付き（Browser ペインの H₂⁺ で −0.5588 Ha を確認）。**電荷を変えるとスキャンの図は消える**
  （`scanOnScreen` が電荷も比べる）。
- **確認してほしい点**（上の 7 に足す）: マーカーを動かしている間、3D の + の印が H に付いてくるか。
  相関図の見出し「H⁺」の上付きの + が小さい画面で読めるか。H₂⁺ を「安定な形にする」→ スキャンで
  谷が図の中に入り「いちばん低いのは … Å」になるか。HeH⁺ は Browser ペインで 0.55〜1.09 Å・谷 0.94 Å
  （形を調整しない 0.78 Å から）。
