# V7-5 3D の原子に +/− の印（viewer）

**依存: V7-3**（`SceneAtom.charge` と `badgeText`。「V7-3 で入ったもの」を見る）

**目的**: イオンにした原子の右上に `+` / `−` の小さな印を出す。アニメーション中も原子について
動く。**Claude の作業ブラウザは WebGL が使えない**ので、見た目の確認は V7-8 でユーザーに頼む。
ここでは DOM の数（印の要素がいくつあるか・文字）を `javascript_tool` で見る。

## 前提（今のコード）

- `web/src/scene/viewer.ts`（約 980 行。丸ごと読まない）:
  - `setMolecule(atoms)`（`grep -n "setMolecule(atoms"`）が `#atoms` を写して `#syncAll()`。
  - `setPositions(positions)` が**`{ z, pos }` を組み直している**
    （`grep -n "setPositions(positions"`）。このままだと**アニメーションの 1 フレーム目で電荷が
    消える**ので、`{ ...this.#atoms[i], pos: … }` に直す。
  - `#syncAll()` が原子・結合・強調・ハンドル・計測・結合の長さのラベルを描き直す。
  - 結合の長さのラベル `#syncBondLabels()`（`grep -n "bond-label"`）が **`CSS2DObject` のプール**
    の手本: 数が減るときは `group.remove(...)`（要素がページから消えるのはこれだけ）、増えるときは
    `new CSS2DObject(labelElement('bond-label'))`、位置と `setText` を毎回入れる。
  - 原子の球の半径は元素の半径 × `SPHERE_SCALE`（0.32）。
- ラベルの層は `CSS2DRenderer`。**z-index は進捗カードより下**（CLAUDE.md）。`App.css` の
  `.measure-label` / `.bond-label` の定義が手本（`grep -n "bond-label" web/src/App.css`）。
- 色: **差密度が青と赤なので、印に青・赤を使わない**。文字色 `#d6dde8`、地はパネル `#151a21`
  か半透明の黒、枠 `#2d3644` のどれか。

## やること

1. **`#syncChargeBadges()`**: 電荷が 0 でない原子ごとに 1 つの `CSS2DObject`
   （`labelElement('charge-badge')`、文字は `badgeText(charge)`）。位置は原子の中心から
   カメラの右上方向に球の半径ぶんずらす（ずらし方はカメラの向きが要るので、簡単にするなら
   中心 + ワールドの上方向に半径でもよい。**見た目の判断は V7-8**）。`#syncAll()` から呼ぶ。
   プールの扱いは `#syncBondLabels` と同じ。
2. **`setPositions` で電荷を保つ**（上の前提）。
3. **CSS**: `.charge-badge`（小さめの太字、丸い地、`pointer-events: none`）。
4. **確かめる**（`javascript_tool`、WebGL が無くても CSS2D の要素は DOM に出るかを先に見る。
   出ないなら、viewer が WebGL 無しで何を作っているかを `grep -n "WebGL" web/src/scene/viewer.ts`
   で見て、確認は V7-8 に回す）: H₂O で H を + にすると `.charge-badge` が 1 つで文字が `+`、
   中性に戻すと 0 個、全消去で 0 個。
5. `badgeText` 以外の文言は足さない（**数値を出さない**）。

## V7-3 で入ったもの

- `scene/viewer.ts` に `export type AtomCharge = -1 | 0 | 1` と `SceneAtom.charge?: AtomCharge`
  （**中性は欄そのものが無い**。読むときは `atom.charge ?? 0` か、そのまま `badgeText(atom.charge)`）。
- `components/ion.ts` の **`badgeText(charge: AtomCharge | undefined): string | null`**（`+`、
  `−`（U+2212）、中性・省略は `null`）。viewer から import しても純粋な `.ts` なので循環しない
  （`ion.ts` は `viewer.ts` から型だけを import している）。

  （印が付いてくるかの確認に使える）。候補と記録から戻す経路は V7-4・V7-6 まで中性に戻る。

## V7-4 で入ったもの

- **ボタン**: 計算タブの `削除` / `全消去` の `ActionGrid` のすぐ下に `<Segmented label={ION_GROUP_LABEL}
  options={ionRow} …>`（目印 `grep -n "The ion row (v7)" web/src/App.tsx`）。押すと `chargeSelected(choice)` が
  選んだ原子だけ `{ z, pos, charge }`（中性は `{ z, pos }`）に作り直して `setAtoms` → `invalidateResult()`。
  **`atoms` の配列が新しくなるので、viewer の `setMolecule(atoms)` の effect は電荷の変更でも走る**
  （位置は変わらない。印の更新はそこに乗せればよい）。
- **電荷が画面に戻る経路は、記録を開く以外すべて保たれる**: 緩和の毎歩と後（`withPositions`）、探索の候補を
  開く（`atomsOfFlat(candidate.z, candidate.start, candidate.charges)`）。記録は V7-6 まで中性に戻る。
- Browser ペインでの確かめ方（WebGL 無しでも原子を選べる）: App の fiber を DOM から辿り、フックの
  `memoizedState` の並びで **3 番が `atoms`・8 番が `selected`・9 番が `mode`**（`App()` の先頭の
  `useRef` 3 つの後。フックを足すとずれる）。`hooks[8].queue.dispatch(1)` で原子を選べる。
