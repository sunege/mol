## v7 で決まっていること（全チケットに効く）

1. **電荷は原子に付ける（`SceneAtom.charge`: −1 / 0 / +1、省略＝0）。エンジンの SCF が使うのは
   合計だけ。** Na⁺ + Cl⁻ は中性の NaCl と同じ計算。原子ごとの値が効くのは**差密度の基準・
   相関図の原子の側（自由原子の準位と軌道）**だけ（SCF の初期値は V7-1 で外した。4 を見る）。
2. **電荷は画面に出す**（F4 の読み替え）: 3D の原子に +/−、記録ツリーの見出しに H₃O⁺。
   **多重度・基底・汎関数・試行回数、原子ごとの計算上の電荷（Mulliken）は出さない。**
3. **合計の電荷は指定どおりに解く。`driver` の「最後の手段で ±1」は無くなる**（V7-1）。
   解けなければ発散のアニメーション（F5）のまま。
4. **「原子から動いた電子」の基準は置いたとおりのイオン**（H⁺ は密度 0）。**SCF の初期値は別の関数で、
   中性原子の重ね合わせを電子数に縮めたもの**（V7-1 で計画から変えた。イオンで始めると Cl₂⁺・He₂⁺ の
   ような対称な荷電分子で穴が片側に寄り、収束が数倍遅いか落ち、印をどちらに付けたかで答えが変わる。
   dev-notes「V7-1 の実装メモ」）。どちらも電子数は分子と一致する。
5. **陰イオン（負の印が 1 つでも）には注意書き。** 文言は V7-0 が決め、V7-3 が `.ts` に置く。
6. **荷電二原子の距離スキャンは範囲を切る。** 上端は平衡距離の **1.4 倍**（V7-0、中性は 1.8）。
   荷電かどうかは**合計の電荷**で決める（Na⁺ と Cl⁻ は中性の NaCl と同じ計算）。プリセットの範囲は中性だけ。
7. **電子が 0 になる組み合わせは押せない**（無効、消さない）。合計は **−2〜+2**（V7-0）。
   **He・Ne・Ar は − にできない**（最小の基底に余分な電子の入る場所が無い。V7-0）。
8. **記録のファイルは version 2**（原子ごとの電荷）。version 1 は全部中性として読む。

理由は [docs/plan-v7.md](../plan-v7.md)。

## トークンを節約する決まり（全チケット）

- **`web/src/App.tsx`（約 2,460 行）を丸ごと読まない。** チケットの「触る場所」にある関数名や
  JSX の目印を `grep -n` で探し、その前後だけ `sed -n` で読む。行番号はチケットを書いた時点の
  目安で、前のチケットでずれている。`App.css`・`components/scan.ts`（約 1,300 行）・
  `scene/viewer.ts`・`crates/dft-wasm/src/lib.rs`（約 1,240 行）・`crates/dft-core/src/driver.rs`
  も同じ。
- **dev-notes と plan-v7.md は読まない**（チケットが節を指したときだけ、その節だけ）。
- **ブラウザでの確認は `read_page` / `javascript_tool` で数値を取る**。スクリーンショットは最後の
  1 枚だけ。dev サーバーは `preview_start` の `mol-dev`（5173 が使用中なら、ユーザーの dev
  サーバーなので `navigate` で `http://localhost:5173` を開く）。

  3D の見た目は **ユーザーに Firefox で見てもらう**（V7-8）。
- **テストは純粋な `.ts` に書く**（vitest は `environment: 'node'`、DOM のテストは無い）。
- 検査は `npm test` と `npm run lint --workspace web` と `npm run build`（型）。
  Rust を触ったら `cargo test --workspace`（V7-1・V7-2 だけ）。

## Rust を触るチケット（V7-1・V7-2）の決まり

- **`cargo fmt` を掛けない**（触った行だけ手で 100 桁に収める）。
- **参照値を記憶から書かない。** テストは独立な経路（`tr(D S)` の電子数、対称性、既存の
  中性の結果との一致）から導くか、V7-0 が `gen_reference.py` で作った生成物を使う。
- **`dft-core` に wasm 依存を入れない。** `dft-wasm` は単位変換とシリアライズだけ。
- **`System` から別の `System` を組む箇所（SAD の原子・最適化の毎歩）は、`kind` と同じく
  原子ごとの電荷も引き継ぐ。**
- `.wasm` を作るのは `npm run build:wasm` だけ（`RUSTFLAGS` で渡さない）。`web/src/wasm/` は
  コミットする。Rust を書き戻すときに `mv` や `cp -p` を使わない。

## 全チケットに共通する前提

- 画面は暗い配色だけ。色は今の `App.css` の値を使う: 地 `#0e1116`、パネル `#151a21`、
  線 `#262d38`、ボタン `#1c222c` / 枠 `#2d3644`、文字 `#d6dde8`、弱い文字 `#7c8798`、
  強調 `#3f8cff` / 選択の地 `#1d3a66`。**緑は DFT を回すボタン（`RunButton`）だけ。**
  差密度の色は青（濃くなった）と赤（薄くなった）なので、**+/− の印に青・赤を使わない**。
- ボタンは 4 つの型だけ（`components/controls.tsx`: `Segmented`・`Choices`・`ActionGrid`・
  `IconButton`、見た目は `.btn`）。**使えないときは消さずに無効。**
- 原子は `SceneAtom`（`scene/viewer.ts`、`{ z, pos, charge? }`。`charge` は V7-3 で増えた
  `AtomCharge`、中性は欄ごと無い）。Worker に渡す配列は `molecules/presets.ts` の `toWorkerArrays(atoms)` が唯一の出口。
- エンジンは原子単位、UI は Å。電荷は単位の変換が要らない（整数のまま越える）。
