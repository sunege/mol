# v6 の計画: 使っていて気になった細部 5 点

**この文書は「なぜこの形なのか」だけを持つ。作業は [docs/v6/README.md](v6/README.md)（板）から。**

v5 までで機能と並べ方は揃った。v6 は、ユーザーが実際に使って引っかかった 5 点を直す
（2026-09-25 相談・決定）。エンジンに新しい物理は入れない。Rust を触るのは原子軌道を描く
2 枚（V6-5・V6-6）だけ。

## 決まったこと

1. **走らせる 2 つ（「安定な形にする」「この形のまま計算」）は計算タブの「次の計算」の下。
   止めるボタンは計算中だけパネルの上に出す**（ユーザーの選択）。
   計算タブを上から読むと「置く → 段を選ぶ → 走らせる」になる。計算を始めると観察タブに
   移る決まり（v5）はそのままなので、止めるボタンを計算タブに入れると計算中に見えなくなる。
   だから止めるほうだけ上に残す。**進捗カードには置かない**（`pointer-events: none` で 3D を
   回せるようにしてある。v5 の決定 2 と同じ理由）。v5 の「中止が押した指の下に来る」は
   走らせるボタンと止めるボタンが別の場所になるので成り立たなくなるが、止める 2 枠
   （「中止」と「すぐ止める」）の位置は固定のまま。
2. **二原子分子では、分子軌道の節の「はしご」を相関図に置き換え、相関図の線から軌道を描く。**
   二原子のはしごは相関図の真ん中の列と同じ中身で、2 枚並べる理由が無い。距離スキャンの節
   （「近づけてみる」）には距離スキャンだけを残す。
3. **原子の側の線からも軌道を描く。縮退した組は「向き」で選ぶ。** 2p の 3 本は 1 つの段に横に
   並べ、左から「結合の軸の向き（pσ）」「軸に垂直・画面の中（pπ）」「軸に垂直・手前（pπ）」。
   分子の π の 2 本も同じ 2 つの垂直な向きにそろえる。原子の pπ とそれがつながる分子の π が
   同じ向きで出るので見比べられ、σ は軸方向の p から・π は垂直な p からという相関図の中身
   そのものを絵で確かめられる。向きは**押したときの画面**から決める（押した後に回しても
   描き直さない）。
   - 回し方: 縮退した組の列 `C` の中で、方向 `d` の p 関数 `t_A`（原子ごと）との重なりの
     二乗和 `M_kl = Σ_A (c_kᵀ S t_A)(c_lᵀ S t_A)` が最大の組み合わせ（`M` の最大固有ベクトル、
     Jacobi）。原子ごとに分けて足すのは、反結合性の π*（2 原子で符号が逆）を和で打ち消さないため。
   - 原子の軌道は、自由原子の計算（`guess::atomic_scf`、SAD の初期値と同じもの）の係数を
     分子の基底のその原子の区画に埋め、ほかを 0 にして今の `evaluate_orbital` に流す。
     分子の基底は原子の順に殻を並べているので、区画は連続で、自由原子の基底と同じ並び。
   - 今は π の組の向きがエンジンの成り行きで斜めに出る。これもあわせて直る。
4. **記録のツリーは選んでも並びが変わらない。分子の順は「その分子の最初の記録」の新しい順**
   （新しい分子が上に 1 行増えるだけで、あとは動かない）。v5 までは画面の分子を先頭に並べ
   替えていた（App の `recordGroups`）。見失わないように、画面の分子の行は色で示す。
   分子と段の「…」から**まとめて消せる**（確認のダイアログ付き。「全部消す」と同じ）。
5. **異性体の注意書きは段ごとに言い分ける。** 実測（dev-notes「v3-0 の実測」の表
   「3. エネルギー: 符号は基底、大きさは汎関数」）: 「形を探す」は 5 組中 2 組
   （環 vs 二重結合、エーテル vs アルコール）で順序が逆、「形を測る」は 5 組すべて順序が合い、
   差の大きさは小さく出る（C₃H₆ −5.4 / 実験 −32.9、C₂H₆O +26.9 / 実験 +49.9）。
   v2 の「当てになりません」は「形を探す」だけの話で、「形を測る」には強すぎる。
6. **座標軸のハンドルはワールドの XYZ**（ユーザーの選択）。選んだ原子に 3 本の矢印を出し、
   矢印をつかむとその軸の上だけを動く。原子をつかめば今までどおり画面の面内。
   three の `TransformControls` は使わない（自分でポインタを取るので、「ポインタとキーの
   解釈は `gestures.ts` だけ」の規約が崩れる）。矢印は原子より先に当たり判定を取り、
   画面上の大きさを一定に保つ。

## 採らなかった案

- **止めるボタンを進捗カードに置く**: カードは 3D の操作を通すために `pointer-events: none`。
- **結合の向きに沿ったハンドル**: 二原子以外では「どの結合か」を選ぶ手間が増える。ワールド
  XYZ で十分（ユーザーの選択）。
- **原子軌道を「どれか 1 本」で描く／縮退の組を重ねて描く**: 1 本だと向きが任意で、
  重ねると球になり、どちらも相関図の σ/π の話とつながらない。
- **分子の並びを分子式のあいうえお順**: 最も動かないが、講義では新しく作った分子を上で
  見つけたい。
