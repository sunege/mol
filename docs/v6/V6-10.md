# V6-10 座標軸のハンドルを描いてつなぐ（viewer）

**依存: V6-9**（`Axis`・`pressAction` の `handle`・`axisParameter`・`axisDragPosition`・
`handleLength`。下の「V6-9 で入ったもの」を見る）

**目的**: 選んだ原子の横に X / Y / Z の矢印を描き、矢印をつかむとその軸の上だけを動かす。
**App はほぼ触らない**（動かした位置は今のドラッグと同じ `onMove` で届く）。

## 前提（今のコード、`web/src/scene/viewer.ts`）

- 選択の印は `#highlight`（`#updateHighlight`、`grep -n "#updateHighlight"`）。選択は
  `setSelected(index)`、モードは `setMode(mode)`。原子は `#atomGroup` の子で、`#pick(event)` が
  `#raycaster.intersectObjects(this.#atomGroup.children, false)` で当てる。
- 押す: `#handlePointerDown`（捕捉フェーズ。原子に当たったら `#controls.enabled = false` にして
  カメラの回転を止め、`setPointerCapture`）。動かす: `#handlePointerMove` が `#dragIndex` の原子を
  `#planePoint(event, 原子の位置)` に動かし `this.onMove?.(index, [x, y, z])`。離す:
  `#handlePointerUp`（動いていなければ `clickAction`）。
- 描画は `tick()` の `requestAnimationFrame` ループ（毎フレーム `render`）。
- **メッシュとマテリアルは再利用し、古い geometry は必ず `dispose()`。** `dispose()` の最後で
  片付ける（`grep -n "dispose()" viewer.ts`）。
- 画面の下端の操作の説明は `web/src/components/viewportHint.ts` の `EDIT_HINT`
  （「クリックで配置 · ドラッグで移動 · Shift+クリックで隣に結合 · 背景のドラッグで回転」、
  テストは `viewportHint.test.ts`）。

## やること

1. **ハンドル**: `#handles: THREE.Group`（矢印 3 本。円柱 + 円錐を 1 本ずつ。X `#e5534b`・
   Y `#57ab5a`・Z `#539bf5`、`MeshBasicMaterial`、`depthTest: false`・`renderOrder` を大きく
   ＝ 原子に隠れない）。各矢印の `userData.axis`。当たり判定用に少し太い透明な円柱を重ねてよい。
   見えるのは `mode === 'edit' && selected !== null` のときだけ（`#updateHighlight` の隣で）。
   位置は選んだ原子、長さは毎フレーム `handleLength(カメラからの距離, fov, 高さ)` で scale。
2. **押す**: `#handlePointerDown` で**先にハンドル**を当てる（`intersectObjects(#handles.children,
   true)`、見えているときだけ）。`pressAction(mode, hit, shift, handle)` が `axisDrag` なら
   `#controls.enabled = false`、`#axisDrag = { index, axis, start: 原子の位置, s0 }`
   （`s0 = axisParameter(光線, start, 軸)`。null なら何もしない）、`setPointerCapture`。
3. **動かす**: `#handlePointerMove` で `#axisDrag` があれば、光線から `s` を出し、
   `axisDragPosition(start, axis, s0, s)` を `onMove` へ。null（軸が見る向きに平行）なら
   その回は動かさない。
4. **離す**: `#axisDrag = null`、`#controls.enabled = true`。`clickAction` にも `handle` を渡す
   （押しただけなら `none`）。
5. **見た目の小物**: ハンドルの上ではカーソルを `grab`（`pointermove` で当たりを見るのは
   ドラッグしていないときだけ・軽く）。任意。
6. **`dispose()`**: 3 本の geometry と material を片付ける。
7. **説明**: `EDIT_HINT` に「矢印のドラッグで軸の向きに移動」を足す（長さが収まるように。
   `viewportHint.test.ts` を合わせる）。

## V6-9 で入ったもの

- `scene/gestures.ts`: `export type Axis = 'x' | 'y' | 'z'`、`export interface HandleHit { axis; index }`。
  `pressAction(mode, hit, shift, handle: HandleHit | null = null)` → 編集で `handle` があれば
  `{ kind: 'axisDrag'; index; axis }`（`index` は `handle.index`、原子に当たっていても Shift でも）。観測は `orbit`。
  `clickAction(mode, hit, shift, handle = null)` → `handle` があれば（モードに関係なく）`{ kind: 'none' }`。
  **既定値が `null` なので viewer は 3 引数のまま**（623 行・655 行あたり、`grep -n "pressAction\|clickAction"`）。
  4 つめを渡すのは V6-10。`#handlePointerUp` は押したときの `handle` を覚えておいて `clickAction` に渡す。
- **新規 `scene/axisDrag.ts`**（three を import しない）: `type Vec3 = [number, number, number]`、
  `axisParameter(rayOrigin, rayDir, point, axis): number | null`（光線は直線扱い、`rayDir` は単位でなくてよい。
  `|cos| > EDGE_ON_COSINE`（0.995）か長さ 0 で null）、`axisDragPosition(start, axis, s0, s): Vec3`
  （`start + (s − s0)·axis`）、`handleLength(distance, fovDeg, viewportHeightPx, px = HANDLE_PIXELS): number`
  （`HANDLE_PIXELS = 60`、`fovDeg` は `camera.fov`＝縦、高さは CSS ピクセル＝`clientHeight`）。
  軸のベクトルは `x → [1,0,0]` などを viewer で引く（`axisDrag.ts` に `Axis` からの表は置いていない）。
  光線は `#raycaster.ray.origin` / `.direction` を `toArray()` で渡せばよい。
