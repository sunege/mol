# V6-5 エンジン: 原子軌道の列と、縮退の組を向きで回す（`dft-core`）

**依存: なし**（`cargo test` だけで完結。wasm・Worker・UI は V6-6 以降）

**目的**: 2 つの純 Rust の関数を `dft-core` に足す。
(a) **自由原子の軌道を、分子の基底の上の係数の列にする**（その原子の区画に埋め、ほかは 0）。
(b) **縮退した組を、方向 `d` を向くように回した 1 本の列にする**（分子の π の組にも、原子の
p の組にも同じ関数を使う）。新しい物理は無い。描くのは今の `density::evaluate_orbital`
（線形、V6-6 がつなぐ）。

## 前提（今のコード）

- 自由原子の計算: `crates/dft-core/src/scf/guess.rs` の非公開 `atomic_scf(z, kind) -> OrbitalSet`
  （単原子の `System` を `GridQuality::Coarse` で組み、`Occupation::SphericalAverage` で解く）。
  公開は `atomic_levels(z, kind) -> Vec<f64>`（その `energies`。これが Worker の `atomLevels` で
  UI に届く並び）。**`energies` が昇順で、`coefficients` の列がその順に対応していることを最初に
  確かめる**（`scf/linalg.rs` の `symmetric_eigen_sorted` を通っているか）。
- `OrbitalSet { energies, coefficients (列 = 軌道), occupations, density }`（`scf/mod.rs`）。
- 基底: `basis/mod.rs` の `BasisSet::build` は**原子の順に**その元素の殻を並べる。だから 1 原子の
  関数は連続した区画で、単原子の `BasisSet` と同じ並び。`offsets` は非公開（殻ごとの先頭の添字と
  末尾の合計）。`Shell { center, l, … }`。デカルトの並びは `cartesian_powers(1) = [x, y, z]`。
- `System { molecule, kind, basis, overlap, … }`（`scf/mod.rs`）。**`System` から別の `System` を
  組むときは `system.kind` を引き継ぐ。**
- `orbital.rs`: `DEGENERACY_TOLERANCE = 1e-4`、`degenerate_groups(&[OrbitalInfo]) ->
  Vec<Range<usize>>`、`list(system, result)`、`signed_column(result, OrbitalRef) -> DVector`
  （**絶対値最大の係数を正にする**。今は符号を決めるのはこれだけ）。`OrbitalRef { channel, index }`
  は `bonding.rs`。
- 固有値分解は **`scf/linalg.rs` の `symmetric_eigen_sorted`**（Jacobi、昇順）。`SymmetricEigen` は
  使わない。

## やること

1. **`basis/mod.rs`**: `pub fn atom_functions(&self, center: usize) -> Range<usize>`（その原子の殻の
   最初の関数から最後の関数の次まで）。テスト: H₂O で O が 0..5、H が 5..6・6..7（STO-3G）、
   区画の和が `n_functions()`。
2. **`scf/guess.rs`**: `pub fn atomic_orbitals(z, kind) -> (System, OrbitalSet)`（向きを決めるのに
   単原子の重なり行列と基底が要るので `System` も返す。`atomic_levels` はこれを使うよう書き換え、
   値は変えない）。
3. **`orbital.rs`**: 向きで回す関数。
   ```rust
   /// 縮退した組（列）を、方向 `along` の p 関数とよく重なる 1 本に回す。
   pub fn oriented(basis: &BasisSet, overlap: &DMatrix<f64>, set: &DMatrix<f64>,
                   along: [f64; 3]) -> DVector<f64>
   ```
   - 原子ごと・p の殻ごとに目標 `t`（その殻の px, py, pz に `along` の成分を置いた列）を作り、
     `M_kl = Σ_t (c_kᵀ S t)(c_lᵀ S t)`（`k×k`、k ≤ 3）。**原子ごとに分けて足す**（π* は 2 原子で
     符号が逆で、和の目標だと打ち消し合う）。
   - `M` の最大固有値の固有ベクトル `a`（`symmetric_eigen_sorted` の最後の列）で `u = C a`。
     `C` は S で正規直交なので `uᵀ S u = 1`。
   - **符号**: `|uᵀ S t|` が最大の目標で `uᵀ S t > 0`（正の側が `along` を向く）。
   - 組が 1 本なら回さず、その列を `signed_column` と同じ規則で符号だけ決める。
   - `M` がほぼ 0（組に p が無い、例えば `along` が σ の方向）のときは組の最初の列を
     `signed_column` の規則で返す。
4. **`orbital.rs`**: 入口を 2 つ。
   - `pub fn molecular_oriented(system, result, orbital: OrbitalRef, along: Option<[f64; 3]>)
     -> DVector<f64>`: `along` が None なら `signed_column` そのもの。あれば `list` と
     `degenerate_groups` で `orbital` を含む組を探し、その列を `oriented` に渡す。
   - `pub fn atomic_column(system: &System, atom: usize, orbital: usize, along: Option<[f64; 3]>)
     -> Result<DVector<f64>, OrbitalError>`（エラー型は今の `orbital.rs` の流儀に合わせる。無ければ
     素直な enum）: `atomic_orbitals(z, system.kind)` を解き、`orbital` を含む縮退の組を
     エネルギーで探し（`DEGENERACY_TOLERANCE`）、`along` があれば単原子の基底と重なりで
     `oriented`、無ければその列を符号だけ決めて、長さ `system.basis.n_functions()` の 0 の列の
     `atom_functions(atom)` に埋める。`atom` と `orbital` の範囲外はエラー。
5. **テスト**（`orbital.rs` の `mod tests`。**参照値は独立な経路から**）:
   - 埋めた列が S で正規化されている（`uᵀ S u = 1`、分子の `system.overlap` で）。
   - N 原子（N₂ の片方）の 2p を `along = z` で: その原子の px・py の係数が ~0、pz が主。
     `along` を任意の単位ベクトル `d` にすると、p の係数の向き（区画の中の px, py, pz を
     S で取った射影）が `d` に平行。
   - N₂ を **軸が斜めの向き**に置き、π の組を 2 つの直交する垂直方向 `d1`, `d2` で回す:
     2 本が S で直交（`u1ᵀ S u2 ≈ 0`）、各々の p 係数の向きが `d1`・`d2` に平行、π*（反結合性）
     でも同じ（原子ごとの目標でなければ落ちる検査）。
   - 符号の規則（正の側が `along`）。組が 1 本の軌道では `signed_column` と一致。
   - 範囲外の `atom` / `orbital` がエラー。
   - 分子の 1 原子の区画以外が厳密に 0。
