# V6-3 走らせるボタンを計算タブへ、止めるボタンは計算中だけ上に

**依存: なし**

**目的**: 計算タブを上から「置く → 段を選ぶ → 走らせる」の順にする。「安定な形にする」
「この形のまま計算」は計算タブの「次の計算」の下へ移し、パネルの上には**計算中だけ**
止める 2 枠を出す（ユーザーの選択。計算を始めると観察タブに移るので、止めるボタンは上に残す）。

## 前提（今の動き）

- 2 枠の表は `web/src/components/actions.ts` の `actionSlots({ computing, stopping, unavailable,
  atomCount })` → `[ActionSlot, ActionSlot]`（`label`・`action: 'relax'|'calculate'|'stop'`・
  `disabled`・`runs`）:

  | 状態 | 左 | 右 |
  | --- | --- | --- |
  | 計算していない | 安定な形にする (relax) | この形のまま計算 |
  | 計算中 | 中止 (stop) | この形のまま計算 (無効) |
  | 一歩の後に止めている | 止めています… (無効) | すぐ止める (stop) |

  `blocked = unavailable || atomCount === 0` なら全部無効。テストは `actions.test.ts`。
- `StatusHeader.tsx` が `<h1>` の下に `ActionGrid columns={2}` で 2 枠を描き（`runs` なら
  `RunButton`、でなければ素の `.btn`）、その下に状態・形の調整・全エネルギーの `<dl>`、最後に
  `!computing && partWay` のとき「もう一度「安定な形にする」を押すと、ここから続きを計算します。」。
- App（`grep -n "<StatusHeader" web/src/App.tsx`）が `slots={actionSlots(...)}` と
  `onAction={(action) => action === 'relax' ? relax() : action === 'calculate' ? calculate() :
  stopCalculation()}`、`partWay={isPartWay(relaxation, solved, stopped)}` を渡す。
- 計算タブ（`grep -n '<TabPanel tab="edit">' web/src/App.tsx`）の並び: プリセット → 配置する元素
  → 削除/全消去 → `<h2>次の計算</h2>` → 段の `Segmented` → `levelHint` → `advice` → コメント
  「The buttons themselves are at the top of the panel (StatusHeader)…」→「安定な形にする」の説明の
  `<p className="hint">` → `<SearchPanel …/>`。
- 計算を始めると観察タブに移る（`switchMode('observe')`）。発散・エラー・中止で元に戻る。

## やること

1. **`actions.ts`** を 2 つの関数に分ける（先頭コメントの表も書き換える）:
   - `runSlots({ computing, unavailable, atomCount })` → `[安定な形にする (relax), この形のまま計算
     (calculate)]`、どちらも `runs: true`、`disabled = blocked || computing`。
   - `stopSlots({ computing, stopping, unavailable, atomCount })` → 計算していなければ `null`。
     計算中: `[中止 (stop), すぐ止める (stop, 無効)]`。止めている: `[止めています… (無効),
     すぐ止める (stop)]`。どちらも `runs: false`。**2 枠の位置は固定**（「すぐ止める」は最初から
     右に無効で出ている。使えないときは消さずに無効、の決まり）。
   - `actionSlots` は消す。テストを書き直す（計算していないと `stopSlots` は null、
     計算中は走らせる 2 つが無効、blocked で全部無効、など今のテストの中身を移す）。
2. **`StatusHeader.tsx`**: `slots` を `stops: [ActionSlot, ActionSlot] | null` に替え、null で
   なければ今の位置（`<h1>` と `<dl>` の間）に `ActionGrid columns={2}` で描く。`partWay` の
   行はここから消す（props も）。先頭コメントを直す。
3. **App の計算タブ**: 「安定な形にする」の説明の `<p className="hint">` の**直後**、`SearchPanel`
   の前に `ActionGrid columns={2}` で `runSlots(...)` の 2 つを `RunButton` で描く（onClick は今の
   `onAction` と同じ振り分け）。その下に `!computing && isPartWay(...)` のとき今の続きの行。
   「The buttons themselves are at the top…」のコメントを直す。`<StatusHeader` には
   `stops={stopSlots(...)}` と、止める押下 → `stopCalculation()`。
4. CSS は足さずに済むはず（`ActionGrid` と `.hint` の既存のもの）。済まなければ
   `grep -n "panel-head" web/src/App.css` の近くだけ。
