**目的**: Claude の作業ブラウザでは見られない 3D の見た目とドラッグ、講義 PC での動きを

## 確認してもらうこと（Firefox、開発機）

1. **ボタン（V6-3）**: 計算タブの上から「プリセット → 配置 → 次の計算 → 安定な形にする /
   この形のまま計算 → いろいろな形を試す」。何もしていないとき上にボタンが無い。計算中は
   観察タブの上に「中止」「すぐ止める」。
2. **相関図（V6-4・V6-8）**: O₂ と、手で置いた N₂ で「分子軌道」を開く。はしごが無く相関図だけ。
   - 分子の線を押すと軌道が出る。π の 2 本は**軸に垂直・画面の中／手前**の向きにそろっている。
   - 原子の 1s・2s・2p の 3 本（軸の向き・画面の中・手前）を押すと、その原子のところに
     その形と向きで出る。原子の pπ と分子の π の向きがそろっている。
   - 3D を回してから押し直すと、向きが新しい画面に合わせて決まる。
   - 「近づけてみる」は距離スキャンだけ。マーカーを動かしても選んでいた軌道が続く。
3. **記録（V6-1・V6-2）**: 記録を開いても分子の並びが変わらない。画面の分子の行に色。
   分子・段の「…」から消せて、確認で「キャンセル」すると何も消えない。注意書きが段ごと。
4. **ハンドル（V6-10）**: 編集モードで原子を選ぶと X/Y/Z の矢印が出る。矢印のドラッグで軸の
   上だけ動く（押しただけでは原子が増えない）。原子のドラッグは今までどおり。観測モードでは
   出ない。原子を消す・選択を外すと消える。矢印が原子に隠れない。

## V6-8 で入ったもの

- 相関図の線はどれも押せる（分子・原子の両側）。原子の線は自由原子の軌道を画面のその原子の位置に描き、
  節の言葉は「O の原子の 2p（結合の軸の向き）。結合する前の、原子ひとつの部屋です。」＋かたまりの数だけ
  （結合性の行・節の数は出ない）。
- **向きは押したときのカメラで決まり、しきい値を動かしても・3D を回しても描き直さない。同じ線を
  押し直すと、そのときの画面で向きを決め直す**（確認 2 の「回してから押し直す」はこれ）。マーカーを
  動かしても向きは押したときのまま。
- 正の塊（色）は `結合の軸の向き` では左の原子 → 右の原子（`atoms[0] → atoms[1]`）の側、手前は画面の
  手前の側。WebGL の無い Claude のブラウザでは標準のカメラ（`+x` 右・`+y` 上・`-z` を見る）で決めたので、
  **画面と向きが合っているかは Firefox でしか分からない**。
- 手で置いた N₂ では内殻（1s）が畳まれて相関図に 1s の線が出ないことがある（V6-7 の `foldCore`）。
  出ないのは不具合ではない。
- 目印: App の `pressOrbital`（節の `onPick`）・`orbitalDirection`・`selectOrbital(pick, direction)`、
  viewer の `cameraAxes()`、`orient.ts` の `pickDirection` / `sameDirection` / `STANDARD_CAMERA`、
  `scan.ts` の `atomPickWords`。

## V6-10 で入ったもの

- 矢印は**原子の中心から少し離れたところ（画面で約 15 px）から**始まる。原子の真ん中は今までどおり
  自由なドラッグでつかめる。3 本が重なったところで迷ったら、ここが見どころ。
- 矢印の上ではカーソルが `grab`、ドラッグ中は `grabbing`。押しても 4 px 動くまでは原子は動かない
  （自由なドラッグと同じしきい値）。
- 軸がほぼ視線と平行なとき、その矢印を押すと**視点が回る**（原子は動かない）。仕様どおり。
- 矢印は**原子・結合・等値面・計測の破線より手前**に描く（`depthTest: false`）。後ろ向きの矢印も
  原子の上に重なって見える。
- 動かした位置は今のドラッグと同じ `onMove` → `moveAtom` を通るので、計算結果が消える・`handBuilt` の
  扱いなどは原子のドラッグと同じ。
- 目印（手直しするとき）: viewer の `#handles`・`#buildHandles`・`#updateHandles`・`#scaleHandles`・
  `#pickHandle`・`#axisDrag`・`#syncCursor`、定数 `AXIS_COLORS`・`HANDLE_START`・`HANDLE_HIT_RADIUS`
  （太さ・つかみやすさはここ）。説明は `viewportHint.ts` の `EDIT_HINT`。

## V6-9 で入ったもの

- 決めた振る舞い（見るときの目安）: 矢印を押して動かさずに離しても**何も起きない**（原子は増えない）。
  矢印をつかんでも原子は**つかんだ点へ跳ばず**、ポインタが動いた分だけ動く。軸がほぼ見る向き
  （画面に垂直）の間は、その軸の矢印を動かしても**原子は止まったまま**（向きを回すと動く）。
  矢印の長さは**画面上で約 60 px** で、ズームしても変わらない。
