# V6-2 分子・段ごとに記録を消す（「…」から）

**依存: V6-1**（同じファイルを触るので後に回す）

**目的**: ツリーの分子の行と段の行の「…」から、その下の記録をまとめて消せるようにする。

## 前提（今の動き）

- 分子の行（`RecordTree.tsx` の `formulaRow`）には `MoreMenu` があり、中身は
  「この分子だけ書き出す」（`WORDS.exportMolecule`）1 つ。**段の行（`levelRow`）には `MoreMenu`
  が無い。** `MoreMenu` の props は `label` と `items: { label, onSelect, disabled? }[]`
  （と任意の `note`）。
- 1 件を消すのは App の `deleteRecord`（`grep -n "const deleteRecord" web/src/App.tsx`）:
  `setRecords(filter)`・`setOpenRecordId(開いていたら null)`・`setRecordNotice(null)`・
  `storeRef.current?.remove(id)`。全部消すのは `clearRecords` で、
  `window.confirm('記録をすべて消します。よろしいですか？')` を出す。
- 保存は `RecordStore`（`web/src/records/store.ts`）: `load`・`put`・`putAll`・`remove(id)`・
  `clear`。実装は `MemoryRecordStore` と IndexedDB のもの（`grep -n "async remove" store.ts`
  で 2 か所）。テストは `store.test.ts`。
- 木のノード（`records/tree.ts`）: `FormulaNode.children: LevelNode[]`、
  `LevelNode.group: LogGroup | null`（候補だけの段は null）、`LogGroup.entries[].record.id`。
  電荷だけ違う群は同じ見出しの段ノードが 2 つになる（**消すのはその群だけ**）。
- 探索の候補（`CandidateNode`）は記録ではない。**消さない**（走っている候補は後で記録になる。
  それは「全部消す」と同じ扱いでよい）。

## V6-1 で入ったもの

- `RecordTree` の props に `currentFormula: string | null`（`RecordExplorer` が渡す）。`formulaRow` の
  行は `className={molecule.formula === props.currentFormula ? 'tree-row current' : 'tree-row'}`。
- 分子の順は `tree.ts` の `recordsOnly` が決める（その分子の最も古い `savedAt` の新しい順、
  `oldestSavedAt`）。App の `recordGroups` は `groupRecords(records)` だけ。**古い記録を消すと
  その分子の「最初の記録」が新しくなり、分子が上へ動くことがある**（仕様どおり）。
- 注意書きは `RecordExplorer` の末尾で `isomerCaveats(groups.map((g) => g.level))` の数だけ
  `<p className="explorer-caveat">`。段の記録を全部消すとその段の注意書きも消える。

## やること

1. **`tree.ts`**: `recordIdsUnder(node: FormulaNode | LevelNode): string[]`（記録の id だけ。
   候補は入れない）。`tree.test.ts` に: 分子 → 全段の記録、段 → その群だけ、候補だけの段 → 空。
2. **`store.ts`**: `removeMany(ids: readonly string[]): Promise<void>` をインターフェースと 2 つの
   実装に足す（IndexedDB は 1 つのトランザクションで）。`store.test.ts` に Memory の分。
3. **文言**（`components/records.ts` の `EXPLORER_WORDS`）: `deleteMolecule: 'この分子の記録を消す'`、
   `levelMore: 'この段の操作'`、`deleteLevel: 'この段の記録を消す'`。確認文は関数
   `deleteConfirm(what: string, count: number)` →
   `` `${what}の記録を ${count} 件消します。よろしいですか？` ``（`what` は `C₃H₆ ` や
   `C₃H₆ の「形を探す」` のように `levelLabel` で組む）。F4 の検査に通す。
4. **`RecordTree.tsx`**: 分子の `MoreMenu` に「この分子の記録を消す」を足す。段の行に
   `MoreMenu`（`label: WORDS.levelMore`）を足し、「この段の記録を消す」。記録が 0 件なら
   `disabled`。props に `onDeleteMany(ids: string[], what: string)` を足し、
   `RecordExplorer.tsx` で App へ通す。段の行の `.tree-row` は分子の行と同じ並び
   （`tree-toggle` の後ろに `MoreMenu`）。
5. **App**: `deleteRecords(ids, what)` を `deleteRecord` の隣に。`window.confirm(deleteConfirm(what,
   ids.length))` が偽なら何もしない。あとは `deleteRecord` と同じ 4 つ（開いていた記録が
   入っていれば `setOpenRecordId(null)`、`removeMany`）。
