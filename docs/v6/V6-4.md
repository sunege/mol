# V6-4 二原子は相関図だけ、分子の側の線から軌道を描く

**依存: なし**（エンジンは触らない）

**目的**: 原子がちょうど 2 個のとき、「分子軌道」の節のはしご（`OrbitalLadder`）を相関図に
置き換え、**相関図の真ん中（分子）の線を押すとその軌道を描く**。相関図は今「近づけてみる」の節の
中にあるので、そこからは外して距離スキャンだけを残す。原子の側の線（左右）はこのチケットでは
押せない（V6-7・V6-8）。

## 前提（今の動き）

- 相関図の組み立ては `web/src/components/scan.ts` の `buildCorrelation(atoms, symbols, levels,
  makeup)` → `CorrelationFigure { width, height, columns, links, core }`（`grep -n "export function
  buildCorrelation"`）。列は左の原子・分子（開殻なら 2 列）・右の原子。段は
  `CorrelationRung`（`grep -n "export interface CorrelationRung"`）: `key`・`x`・`y`・`half`・
  **`lines: number[]`（線の中心の x。π なら 2 本）**・`mark`・`tag`・`label`・`name`・`count`…。
  分子の段の `key` は `` `${level.spin}:${level.first}` ``。文言は全部 `scan.ts` が作り、
  `correlationTexts(figure)` を `scan.test.ts`（`describe('the correlation diagram'`）が歩いて
  数値が出ないことを見ている。
- 描いているのは `web/src/components/DistanceScan.tsx` の `correlation` の `<svg className=
  "correlation">`（`CORRELATION_HEADING`・`CORRELATION_HINT` の見出しと説明付き）。props の
  `atomLevels`・`levels`・`weights`・`symbols` は相関図のためだけにある。
- App（`grep -n "<DistanceScan" web/src/App.tsx`）が `atomLevels={freeAtomLevels}`・
  `levels={orbitalLevels}`・`weights={orbitalWeights}`・`symbols=…` を渡す。
  - `freeAtomLevels` の effect（`grep -n "const scanPairKey"`）は **`scanOpen` のときだけ**
    `client.atomLevels(...)` を取る。
  - `orbitalWeights` の effect（`grep -n "setOrbitalWeights(\[\])"`）は `orbitalLevels !== null &&
    atomCount === 2` で取る（節の開閉には依らない）。
- 分子軌道の節は `web/src/components/OrbitalPanel.tsx`: `levels === null` なら読み込み中/要計算の
  文、あれば `ORBITAL_INTRO` → `<OrbitalLadder levels picked onPick />` → 選んでいればしきい値と
  性格の言葉（`rungOf(levels, picked)` で段を引く）。App は `<OrbitalPanel` に
  `picked={orbitalPick}`・`onPick={selectOrbital}`・`symbols={orbitalSymbols}` などを渡す。
- 選択は `OrbitalPick { index, spin }`（`components/orbital.ts`）。**`index` はスピンの組の中の
  軌道の添字**で、段なら `level.first + (0..count)`。`samePick(a, b)` で比べる。
- 二原子のプリセットは O₂（開殻、分子の列が 2 列）。N₂・H₂ は手で置く。

## やること

1. **`scan.ts`**: `CorrelationRung` に `picks: (OrbitalPick | null)[]`（`lines` と同じ長さ）と
   `lineLabels: string[]` を足す。分子の段は `{ index: level.first + k, spin: level.spin }`、
   原子の段は `[null]`。`lineLabels` は段の `label`、2 本なら「…、1 つめ」「…、2 つめ」。
   `correlationTexts` に `lineLabels` も入れる（数値が出ない検査に掛かる）。
   `orbital.ts` からの型の import で循環しないか確かめる（`orbital.ts` は `scan.ts` を import
   していない）。
   テスト: 分子の線の `picks` がはしごの軌道と 1 対 1（O₂ の形の入力で、両スピン・π の 2 本が
   `first` と `first + 1`）、原子の線は null。
2. **新規 `components/CorrelationDiagram.tsx`**: `DistanceScan.tsx` の相関図の SVG をそのまま
   移し、props は `{ figure, picked, onPick }`。`picks[k]` が null でない線ごとに、透明な当たり
   判定の `<rect className="correlation-hit">`（線の幅 × 高さ 12 ほど）を `role="button"`・
   `tabIndex={0}`・`aria-label={lineLabels[k]}`・`aria-pressed={samePick(...)}` で重ね、
   クリックと Enter/Space で `onPick`。選ばれた線は `correlation-line picked`。
3. **`OrbitalPanel.tsx`**: props に `correlation: CorrelationFigure | null` と
   `diatomic: boolean` を足す。`diatomic` なら `OrbitalLadder` の代わりに `CORRELATION_HEADING`
   は出さず `CORRELATION_HINT` と `<CorrelationDiagram>`（`correlation` がまだ null なら
   `ORBITAL_LOADING`）。しきい値・性格の言葉はそのまま（`rungOf` は同じ pick で引ける）。
4. **`DistanceScan.tsx`**: 相関図の部分と `atomLevels`・`levels`・`weights`・`symbols` を消す。
   先頭コメントを直す（相関図は分子軌道の節へ移った）。
5. **App**: `freeAtomLevels` の effect の条件を `scanOpen` から **`orbitalsOpen`** に替える
   （依存配列も）。`useMemo` で `buildCorrelation(freeAtomLevels, symbols, orbitalLevels,
   orbitalWeights)` を作り（原子 2 個で、どちらも揃っているときだけ。`DistanceScan` にあった
   条件を写す）、`<OrbitalPanel correlation={…} diatomic={atoms.length === 2}>`。
   `<DistanceScan` から消した props を外す。
6. **CSS**（`grep -n "\.correlation" web/src/App.css`）: `.correlation-hit { fill: transparent;
   cursor: pointer; }`、`.correlation-line.picked { stroke: #3f8cff; }`、フォーカスの輪郭。
