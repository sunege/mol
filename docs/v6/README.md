## v6 で決まっていること（全チケットに効く）

1. **走らせる 2 つは計算タブの「次の計算」の下。止める 2 枠は計算中だけパネルの上**（V6-3）。
2. **二原子（原子がちょうど 2 個）では、分子軌道の節のはしごを相関図に置き換える。**
   距離スキャンの節には距離スキャンだけを残す（V6-4）。
3. **縮退した組は向きで選ぶ。** 原子の 2p（3p）の 3 本は左から「結合の軸の向き」「軸に垂直・
   画面の中」「軸に垂直・手前」。分子の π の 2 本は後の 2 つ。向きは**押したときの画面**で決め、
   後で回しても描き直さない（V6-5〜V6-8）。
4. **記録ツリーの分子の順は「その分子の最初の記録」の新しい順で、選んでも動かない**（V6-1）。
5. **座標軸のハンドルはワールドの XYZ**（V6-9, V6-10）。
6. **F4 はそのまま。** 注意書きに段の名前（`levelLabel`）は出してよいが、基底・汎関数・電荷・
   多重度は出さない。軌道・向きの言葉にも数値を出さない（距離スキャンの横軸だけが例外のまま）。
7. **等値面は常に 1 つ、軌道の格子は 1 本だけ**（原子の軌道も同じ 1 本の枠を使う）。

理由は [docs/plan-v6.md](../plan-v6.md)。

## トークンを節約する決まり（全チケット）

- **`web/src/App.tsx`（約 2,400 行）を丸ごと読まない。** チケットの「触る場所」にある関数名や
  JSX の目印を `grep -n` で探し、その前後だけ `sed -n` で読む。行番号はチケットを書いた時点の
  目安で、前のチケットでずれている。`App.css`（約 1,100 行）・`components/scan.ts`
  （約 1,250 行）・`scene/viewer.ts`（約 780 行）も同じ。
- **dev-notes と plan-v6.md は読まない**（チケットが節を指したときだけ、その節だけ）。
- **ブラウザでの確認は `read_page` / `javascript_tool` で数値を取る**（並び・無効かどうか・
  件数）。スクリーンショットは最後の 1 枚だけ。dev サーバーは `preview_start` の `mol-dev`
  （5173 が使用中なら、ユーザーの dev サーバーなので `navigate` で `http://localhost:5173` を開く）。
- **Claude の作業ブラウザは WebGL が使えない**（3D は出ないがパネル・Worker は動く。計算も回る）。
  3D の見た目とドラッグは **ユーザーに Firefox で見てもらう**（V6-11）。
- **テストは純粋な `.ts` に書く**（vitest は `environment: 'node'`、DOM のテストは無い）。
  `.tsx` は薄くして、文言と並びは `.ts` で決める。
- 検査は `npm test` と `npm run lint --workspace web` と `npm run build`（型）。
  Rust を触ったら `cargo test --workspace`（V6-5・V6-6 だけ）。

## Rust を触るチケット（V6-5・V6-6）の決まり

- **`cargo fmt` を掛けない**（触った行だけ手で 100 桁に収める）。
- **参照値を記憶から書かない。** テストは独立な経路から導く（重なり行列での直交・正規化、
  向きの内積など）。
- **`nalgebra` の `SymmetricEigen` は使わない**（`scf/linalg.rs` の Jacobi）。
- **`dft-core` に wasm 依存を入れない。** `dft-wasm` は単位変換とシリアライズだけ。
- `.wasm` を作るのは `npm run build:wasm` だけ（`RUSTFLAGS` で渡さない）。`web/src/wasm/` は
  コミットする。Rust を書き戻すときに `mv` や `cp -p` を使わない。

## チケットを終えるときにやること

1. **この板の状態を書き換える**（1 行）。
2. **実測・却下した案は dev-notes の「フェーズの記録」に 1 節**足す（「V6-n の実装メモ」）。
   チケット本文には書かない。
3. **後のチケットが頼ることが分かったら、そのチケットに「V6-n で入ったもの」を足す**
   （名前・props・CSS クラス・ずれた目印）。次のセッションはそれしか読まない。
4. **規約が変わったら CLAUDE.md の該当行を書き換える**（チケットに「CLAUDE.md」の項があれば
   それ）。増えていないなら触らない。
5. コミットはユーザーに言われたときだけ。

## 全チケットに共通する前提

- 画面は暗い配色だけ。色は今の `App.css` の値を使う: 地 `#0e1116`、パネル `#151a21`、
  線 `#262d38`、ボタン `#1c222c` / 枠 `#2d3644`、文字 `#d6dde8`、弱い文字 `#7c8798`、
  強調 `#3f8cff` / 選択の地 `#1d3a66`。**緑は DFT を回すボタン（`RunButton`）だけ。**
- ボタンは 4 つの型だけ（`components/controls.tsx`: `Segmented`・`Choices`・`ActionGrid`・
  `IconButton`、見た目は `.btn`）。**使えないときは消さずに無効。**
- 軌道の選択は `OrbitalPick`（`components/orbital.ts`、`{ index, spin, atom?, along? }`。後の 2 つは V6-7）。App の
  `orbitalPick` が唯一の状態で、等値面の `channel` はそこから導く（縮退の組の向きは V6-8 から並走する
  `orbitalDirection`、pick と同じ場所で立てて捨てる）。
