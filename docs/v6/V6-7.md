# V6-7 相関図の原子の側と向き（純粋な部分とテスト）

**依存: V6-4**（`CorrelationRung.picks` / `lineLabels`。下の「V6-4 で入ったもの」を見る）

**目的**: 相関図の左右（自由原子）の線も選べるようにする**純粋な部分**を作る。
(1) 原子の縮退した組（2p・3p）を 1 つの段に横 3 本で描き、線ごとに「向き」を持たせる。
(2) 選択の型 `OrbitalPick` に「原子の軌道」と「向き」を足す。
(3) 向きの名前と、画面（カメラ）と結合の軸から実際の方向ベクトルを出す関数。
つなぐのは V6-8。`.tsx` と App はこのチケットでは触らない。

## 決まっていること

- **向きは 3 つ**: `type Along = 'axis' | 'across' | 'toward'`。
  - `axis`: 結合の軸の向き（pσ）。
  - `across`: 軸に垂直で、**画面の面内**（`axis × forward` を正規化。結合がほぼ見る向きを
    向いていて長さが短すぎるときは、カメラの上向きから軸の成分を除いたもの）。
  - `toward`: 軸にも `across` にも垂直で、**手前**（見る人の側を正にする）。
- 原子の p の組の 3 本は左から `axis`・`across`・`toward`。s の段は向きなし（`null`）。
- 分子の段: 2 本の段（π）は `across`・`toward`、1 本の段は向きなし。
- 言葉（数値を出さない）: `axis` 「結合の軸の向き」、`across` 「軸に垂直・画面の中」、
  `toward` 「軸に垂直・手前」。

## やること

1. **`orbital.ts`**: `export type Along = 'axis' | 'across' | 'toward'`。`OrbitalPick` に任意の
   `atom?: number`（あれば `index` はその原子の自由原子の軌道の添字＝`atomLevels` の並び、
   `spin` は `'both'`）と `along?: Along` を足す。`samePick` は 4 つとも比べる（`undefined` どうしは
   同じ）。`rungOf` は `atom` があれば null。`carryPick` は `atom` があればそのまま返し、分子の
   pick では `along` を引き継ぐ。`ALONG_WORDS: Record<Along, string>`。
   `atomOrbitalWords(symbol, name, along)` → 例「N の原子の 2p（結合の軸の向き）。結合する前の、
   原子ひとつの部屋です。」（分子の性格の言葉の代わりに V6-8 が出す）。
2. **`scan.ts`**: `atomColumn` で、名前のついた組（`2p` + `''` + `''`）を 1 段・3 本
   （`count: 3`、分子の π と同じ横並びの計算）にまとめる。`picks` は
   `{ index: at + k, spin: 'both', atom: side, along: ['axis','across','toward'][k] }`、s は
   `{ index: at, spin: 'both', atom: side }`。`lineLabels` に向きの言葉。名前が付かない（全部 `''`）
   ときは今どおり 1 エネルギー 1 段で、`along` なし。分子の π の段の `picks` に `along`
   （`across`・`toward`）を足す。`correlationLinks` は枠 → 段の対応で引く（線の端は段の端）。
3. **新規 `components/orient.ts`**: `type Vec3 = [number, number, number]`、
   `directionOf(along: Along, from: Vec3, to: Vec3, camera: { right: Vec3; up: Vec3; forward: Vec3 })
   : Vec3`（単位ベクトル。`forward` は見ている向きで、手前は `-forward`）。
4. **テスト**:
   - `scan.test.ts`: N₂ の形の入力で、原子の 2p が 1 段 3 本・`picks` の `along` が左から
     `axis, across, toward`・`index` が元の添字（内殻を畳んでも 2p は 2, 3, 4）。s は 1 本。
     線の数（`links`）と結ぶ先の段が今と同じ（段がまとまっただけ）。O₂（開殻）でも同じ。
     `correlationTexts` に数値が出ない（新しい言葉を含めて）。
   - `orbital.test.ts`: `samePick` が `atom`・`along` で区別する、`carryPick` の 2 つの場合。
   - `orient.test.ts`: 軸が x・カメラが標準（right = x, up = y, forward = −z）のとき、
     `across` は +y（`x × (−z)`）、`toward` は +z。軸が見る向き（z）に平行なときは up 由来。
     軸が斜めのとき 3 本が互いに直交し、`across` は画面の面内（`forward` との内積 0）、
     `toward` と `-forward` の内積が正。

## V6-4 で入ったもの

- **`CorrelationRung` に 2 欄**（`scan.ts`、`grep -n "export interface CorrelationRung"`）:
  `picks: (OrbitalPick | null)[]` と `lineLabels: string[]`（どちらも `lines` と同じ長さ）。
  分子の段は `picks[k] = { index: level.first + k, spin: level.spin }`、`lineLabels[k]` は段の
  `label`、2 本以上なら `` `${label}、${k + 1} つめ` ``。**原子の段は今 `picks: [null]`・
  `lineLabels: [label]`**。`scan.ts` は `OrbitalPick` を `./orbital` から `type` で import 済み（循環なし）。
- `atomColumn` の段は `kept[side].map(({ name }, at) => { const words = …; const label =
  words.join('、'); return { … }; })` のブロックになった（`at` は `kept` の添字。**元の `energies`
  の添字ではない**ので、やること 2 で `kept` に元の添字を持たせる）。分子の段は `offsets`
  （`0..count-1`）から `lines`・`picks`・`lineLabels` を作る。
- **`correlationTexts` は `lineLabels` も返す**ので、向きの言葉も数値の検査に自動で掛かる。
- テスト: `scan.test.ts` の `describe('the correlation diagram'` に
  `'makes every line of the molecule a pick of the ladder, and no atom’s'`（O₂ の形。**原子の線は
  `[null]` と見ている**ので、原子を押せるようにしたらこのテストの原子の部分を書き換える）。
- **`components/CorrelationDiagram.tsx`**（新規）: props は `{ figure, picked, onPick }`。
  `picks[k] !== null` の線だけ、線ごとの `<g className="correlation-orbital">` の中に透明な
  `<rect className="correlation-hit">`（幅 `CORR_LINE`、高さ `HIT_HEIGHT` 12、線の 3 上まで）を
  `role="button"`・`tabIndex={0}`・`aria-label={lineLabels[k]}`・`aria-pressed` で重ね、クリックと
  Enter/Space で `onPick(pick)`。選ばれた線は `correlation-line picked`。比較は `samePick(pick, picked)`。
  **段の `<g>` は `picks` が全部 null のときだけ `role="img"`**（img の子は読み上げから消えるので、
  ボタンを持つ段は役割なし）。→ **原子の `picks` を埋めれば `.tsx` を触らずに押せる線になる。**
- CSS（`App.css`、`grep -n "correlation-orbital"`）: `.correlation-orbital`（pointer）・
  `.correlation-hit`（透明）・`:hover` で線 `#8fc0ff`・`.correlation-line.picked`（`#3f8cff`、太さ 3）・
  `.correlation-hit:focus-visible` の輪郭。
- `CORRELATION_HEADING` は消した。`CORRELATION_HINT` の末尾に「まん中の線を押すと、その部屋の形を
  描きます。」を足した（原子の線が押せるようになったら V6-8 で直す）。
