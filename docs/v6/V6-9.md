# V6-9 座標軸のハンドル（純粋な部分とテスト）

**依存: なし**

**目的**: 選んだ原子を**ワールドの X / Y / Z 軸の上だけ**動かすハンドルの、WebGL の要らない
部分を作る: (1) 押したものの解釈（`gestures.ts`）、(2) 光線と軸の線からの位置の計算、
(3) 画面上で一定の大きさにする長さ。描くのと viewer への組み込みは V6-10。

## 決まっていること

- **軸はワールドの XYZ**（ユーザーの選択）。色は X 赤・Y 緑・Z 青（V6-10）。
- **編集モードで、原子が選ばれているときだけ**出る。観測モードでは出ない・つかめない。
- **ハンドルは原子より先に当たり判定を取る**（原子の手前にも奥にも描く）。
- 原子そのものをつかんだら今までどおり画面の面内（`drag`）。Shift は今どおり。
- ハンドルを押して動かさずに離したら**何もしない**（`place` にしない。空間クリックで原子が
  増えると困る）。
- つかんだ点に原子が跳ばないよう、**押したときの軸上の位置からの差だけ**動かす。
- 軸が見る向きとほぼ平行（`|ray · axis| > 0.995`）の間は動かさない（位置が発散する）。

## 前提（今のコード）

- `web/src/scene/gestures.ts`: `pressAction(mode, hit: number | null, shift) → PressAction`
  （`{ kind: 'drag'; index }` / `{ kind: 'orbit' }`）、`clickAction(mode, hit, shift) →
  ClickAction`（`place`・`attach`・`select`・`measure`・`none`）、`keyAction`。テストは
  `gestures.test.ts`。**ポインタとキーの解釈はこのファイルだけ**（規約）。
- viewer（`scene/viewer.ts`）の `#handlePointerDown` が `#pick(event)` で当たった原子を取り、
  `pressAction` に渡す。動かすのは `#handlePointerMove` → `this.onMove?.(index, [x, y, z])`
  （App は今のドラッグと同じ道で受ける）。

## やること

1. **`gestures.ts`**: `export type Axis = 'x' | 'y' | 'z'`。`pressAction` に 4 つめの引数
   `handle: Axis | null`（押したところにハンドルがあったか）と、どの原子のハンドルかを渡す形に
   する（例 `pressAction(mode, hit, shift, handle?: { axis: Axis; index: number } | null)`）。
   編集モードで `handle` があれば `{ kind: 'axisDrag'; index; axis }`（Shift でも）。観測モードは
   `orbit`。`clickAction` も同じ引数を受け、`handle` があれば `none`。
2. **新規 `scene/axisDrag.ts`**（three を import しない。`type Vec3 = [number, number, number]`）:
   - `axisParameter(rayOrigin: Vec3, rayDir: Vec3, point: Vec3, axis: Vec3): number | null` —
     軸の線 `point + s·axis` の上で、光線にいちばん近い点の `s`。`|rayDir · axis|`（正規化後）が
     0.995 を超えたら null。
   - `axisDragPosition(start: Vec3, axis: Vec3, s0: number, s: number): Vec3` = `start + (s − s0)·axis`。
   - `handleLength(distance: number, fovDeg: number, viewportHeightPx: number, px = 60): number` —
     カメラからの距離で画面上 `px` ピクセルになる長さ
     （`2 · distance · tan(fov/2) · px / viewportHeightPx`）。
3. **テスト**（数は独立に作る）:
   - `gestures.test.ts`: 編集でハンドル → `axisDrag`（原子に当たっていても・Shift でも）、観測で
     ハンドル → `orbit`、ハンドルのクリック → `none`、ハンドル無しは今までどおり。
   - `axisDrag.test.ts`: 光線が軸と交わるとき `s` がその交点、ねじれの位置で最近点
     （例: 軸 x・原点、光線が (2, 1, 5) から −z 向き → s = 2）、軸に平行な光線 → null、
     `axisDragPosition` が `s − s0` だけ進む、`handleLength` が距離に比例し、
     fov 90° / 高さ 600px / 距離 10 / 60px で 2。
